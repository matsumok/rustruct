# charta

グラフ描画のクレート。役割と依存の向きは `docs/stack.md`、今の継ぎ目は `src/lib.rs` の先頭、見た目の規則は `docs/design/README.md`。

## 設計メモ（2026-09-30）

- Rust の単独クレートとして汎用に作る。rustruct はその使い手の一つ。3次元も含める。地図は入れない
- 短期的な成果は気にしない。設計を楽しむ
- 課題図（8枚）：層間変形角図／応答スペクトル（Sa–T）／三軸（トリパタイト）応答スペクトル／必要スラブ厚のコンター／応力のコンター／時刻歴＋履歴ループ＋再生／3次元のモード形／風車タイリング
- 座標変換は matplotlib・Makie 型の2段：非線形の目盛り変換 → アフィン変換。逆変換（当たり判定）も同じ段をたどる
- 描き手に依存しない中間表現（シーン：パス・四角・文字・点の記号・格子の場）を背骨にする。描き手候補は SVG・wgpu・静的 SVG・egui
- 反応性は Dioxus のシグナルに直接依存せず、自前の小さなリアクティブ層を持つ（Makie 型）
- 他ライブラリから持ち帰ること：再計算しても拡大範囲を保つ（Plotly `uirevision` 相当の「表示の世代」番号）／選択はグラフではなくものの ID に付けて共有する（Bokeh）／必要な所だけ計算し直す（Vega）／文字は SVG・データは差し替え層・カーソルは上の層（uPlot）／スマホの拡大は下の範囲バー（ECharts）
- インタラクションの5段階：読み取り・拡大・連動・再計算・再生。2本指の拡大は使わない
- 「軸・格子・等値線をガイドとして統一する」（g(x,y)=c の線の集まり）は議論継続中
- 等値線上の数値は白抜き文字を重ねる方式を既定にした
