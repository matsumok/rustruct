# 図（charta）

グラフ描画のクレート charta の言葉。rustruct の Tool に依らない、図そのものの言葉を置く。量の名前と値の求め方は各 Tool の GLOSSARY、サイト全体の言葉は `GLOSSARY.md` に従う。

## Language

### 図の形

**描く範囲**:
図の中で、データの座標を画面に写す矩形。枠で囲み、目盛りを付ける。1 枚の図に 2 つ以上あってよい。
_Avoid_: プロット領域、描画領域

### 点を指す

**指した点**:
利用者が図の上で指しているデータの点。描く範囲の中にだけある。マウスで追っている点と、クリック・タップで止めた点の両方を指す。
_Avoid_: 読み取り（入力の側で、欄の文字を型に読むこと）、カーソル、プローブ

**点の値**:
指した点の座標と、その点での量の値を並べた 1 行。図の下に置く。値は図の素の計算が出し、図の帯や格子からは読まない。
_Avoid_: 読み値、ツールチップ

**当たり判定**:
画面の点が図のどの物に当たるかを決め、当たった描く範囲のデータの点に戻すこと。今の当たる物は描く範囲だけ。
_Avoid_: ヒットテスト
