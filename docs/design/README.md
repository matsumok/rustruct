rustruct は、構造計算のツール（Tools）、材料や規格の値（Data）、数学やかたちの可視化（Studies）、文章（Notes）を一つの住所に並べる個人サイト。箱で区切らず、余白と文字の大きさの差で組む。飾りのためには何も置かない。

## 性格

- 軽い。画像や影や動きに頼らず、文字と罫線と余白だけで成立させる。重く見えるものは入れない。
- 住所で組む。サイト名はドメインそのもの `rustruct.matsumok.com`。各項目には `/studies/pinwheel` のようなパスを `path` で添える。今いる場所は、iPad・PC ではヘッダーのサイト名の右の住所（パンくず）、スマホではメニューの住所の木で示す。
- 振れ幅で階層を作る。`display` 30px・`title` 22px は細く（300）、それ以外は 13px と 11px に落とす。中間の大きさは作らない。
- 一覧は「名前＋一行」。作品も記事も、タイトルと一行の説明とパスだけで並べる。

参照している温度感：takram、rsms.me、tylerxhobbs.com、Order。避けるもの：ごちゃつき、重さ、ありがちな管理画面の型（灰色の地に白いカードが並ぶ形）。

## 色

- 地は `paper` 一色。セクションや項目を塗った箱で囲まない。
- `fill` は意味が2つだけ：「書けない」（ツールの計算セル・行見出し）と「図の下地」（Studies の図版）。飾りの面には使わない。
- 書ける場所は `paper` の地に `line-strong` の枠。塗り＝書けない、枠＝書ける、という読み方を崩さない。
- 文字は `ink` と `muted` の2段。ラベル・パス・日付・補足は `muted`。
- `ng` は NG 判定と入力エラーにだけ使う。警告は色を使わず「!」と文言で示す。
- 線は `line` の 1px が基本。セクション見出しの上だけ `ink` の 1px を引いて区切る。
- メニューを開いたときだけ、本文とヘッダーに `scrim` の幕を掛ける。ほかの面には使わない。
- ダークテーマは同じ役割名で切り替わる。マークアップに色の値を直接書かない。
- コントラストは機械で検査する。tokens.json の `usage` にある WCAG 比（3:1 / 4.5:1）を必須、APCA を警告とし、Rust のテストで見る（テストはまだ無い）。

## 差し色

- 差し色は `accent`（藍）の1色相だけ。プライマリーは `ink` のまま（主ボタン、リンク、選択セルは墨）。
- 使う場所は3つに限る：今いるセクションの下線、新着の点、図の中の一か所。サイト名 `rustruct.matsumok.com` のドットは `accent` にしない（`.matsumok.com` ごと `muted`）。（トップの一文の句点は、一文を `rustruct.matsumok.com` にしたのでやめた。ADR site-0007）
- 面を塗るときの薄い段は `accent-soft`。線と文字には使わない。

## グラフの色

- 系列の色は `chart-1` から順に使う：琥珀 `chart-1`、青碧 `chart-2`、墨 `chart-3`（= `ink`）、紅 `chart-4`、青紫 `chart-5`。
- 5色は、Radix の色（と墨）から総当たりで選んだ。条件は、白地と暗い背景の両方で 3:1 以上、彩度（OKLCH）0.08 以上、一般的な色覚で OKLab 距離 0.12 以上、色覚の違い（Machado・Brettel の両モデル）で 0.05 以上。その中で、2px の線での色覚の違い込みの見分けやすさ（Szafir の線モデル）が最大になる組と並び。
- 先頭から何色取っても強い並びにしてある。系列が少ないときは先頭から使う。
- 差し色の `accent`（藍）とは別に管理する。グラフの中で藍を使うのは、図の一か所の強調だけ。
- 色だけで区別させない。系列ごとに点の形を変える：● ■ ▲ ◆ ▼。凡例の文字は `ink` か `muted` で書き、横に色の線と点を添える。
- 図の形は matplotlib 型：描く範囲を `ink` 1px の四辺の枠で囲み、目盛りは内向きで四辺に付ける（数値は下と左だけ）。格子は既定で引かない。
- 凡例の位置は指定できる：図の中の8か所（四隅と四辺の中央）、図の外（上・右・下）、`auto`（重なりが一番少ない所）。スマホ幅では下に出す。詳しくは Chart。
- 6系列以上は描かない。グラフを分ける。
- `ng` はデータの色に使わない。制限値超過の点だけ `ng` にし、必ず「NG」の文字を添える。
- 枠と目盛りの線は `ink`、目盛りの数値と軸の名前は `muted`、格子（引くときだけ）は `line`。制限値や目標の線は `muted` の破線（墨は系列の色なので使わない）。
- 風車タイリングのような2色塗りは、`accent` と `chart-2`（藍×青碧）。
- wgpu などで描くときも同じ値を使う。値は sRGB なので、sRGB の出力形式で描く場合は線形に変換してから渡す。

## 濃淡の色（コンタ）

- 応力や変位のコンタ・濃淡図は、藍の一色グラデーション `seq-1`〜`seq-12` を使う。差し色の `accent` と同じ藍なので、サイトの中で浮かない。
- 作り方：Radix indigo の 2・5・9・11・12 段目を通り、OKLab で等間隔になるように補間した 12 段。ライトは白→藍（#f7f9ff→#1f2d5c）、ダークは暗い藍→明るい藍（#141726→#d6e1ff）。どちらも値が大きいほど地から遠く、目立つ。
- 明るさだけで段を分けるので、色覚の違い（Machado・Brettel）でも見え方がほぼ変わらない。12 段で隣の段 0.045、1段以上離れた段 0.110（OKLab）。
- 段数を変えるときは 12 色の間を補間して取る（6 段なら 1 つおき）。範囲は図ごとに合わせ、閾値で色を変えない。
- 正負のある量（曲げモーメント、引張と圧縮、差分）は、藍←灰→琥珀の両方向グラデーション `div-1`〜`div-12` を使う。負が藍（`div-1` 側）、正が琥珀（`div-12` 側）、0 は `div-6` と `div-7` の境。範囲は 0 を中心に正負で同じ幅にとる。
- 両方向の作り方：負側は Radix indigo 12・9・5 段目、正側は amber 5・9・11 段目と暗い琥珀 #4f3422 を通り、中央の灰 #f4f4f6 で継いで左右それぞれ OKLab で等間隔にした。ダークは中央が暗い灰 #2a2a2e で、端が明るい藍 indigo-11 #9eb1ff と明るい琥珀 amber-12 #ffe7b3。色覚の違いを含めて、隣の段 0.039、離れた段 0.086（ダークは 0.044・0.106）。
- 一方向の `seq` と同じ藍から始まるので、正負がなければ `seq`、あれば `div` と切り替えても図の印象が揃う。
- 虹（藍→青紫→青碧→琥珀→淡い黄）は候補だったが、採らない（2026-10-23、ADR site-0011）。等値線を1本ずつ追うときは、線の上の数値で読む。
- 最大値の強調や NG は色で表さず、`ng` の印と「NG」の文字で示す。

## 文字

- 和文は IBM Plex Sans JP、数字・パス・サイト名は IBM Plex Mono（Google Fonts から配信）。
- 見出しの太さは 300。太字（500）は `heading` と `wordmark` だけ。
- 数値は必ず `num`（等幅）で右揃え。単位は数字に付けず、表の名前か列の見出しに括弧で書く（「γ（kN/m³）」。ADR site-0006）。
- Notes の本文だけ `prose`（15px / 28px）。ほかの本文は `body`。
- 例外は分布図の等値線の上の数値だけで、9px にする（ADR site-0011）。
- 欧文の斜体は IBM Plex Sans の本物のイタリックを使う。和文フォントを機械的に傾けない。
- 文言は短く言い切る。「！」や絵文字は使わない。見出しは体言止め（「風車タイリング」「梁の断面検定」）。
- トップの一文は `display` で `rustruct.matsumok.com` を置く。
- Notes の本文は iPad・PC で2単位の幅（17px で1行約 40 字）。

## 余白と形

- ページ左右の余白はスマホ `space-5`、iPad（768px〜）`space-7`、PC（1024px〜）`space-8`。セクション間は `space-7`、トップの一文の上下は `space-8`。縦の余白は画面幅で変えない（ADR site-0007）。
- シェルの寸法は tokens の `layout` に名前で持ち、値は `space-<n>` の参照にする。画面左右の余白は `margin`（`px-margin-sm md:px-margin-md lg:px-margin-lg`。本文・ヘッダー・メニューの左右で、殻の1つの部品が持つ）、計算のページの列の区切りの左右の空きは `gap`（`md:gap-gap-md lg:gap-gap-lg`）、ヘッダーの高さは `header`（`h-header`。メニューの一番上の行と `scroll-padding-top` も同じ）。
- 余白は tokens の段だけを使い、段を増やさない。`space-9` は計算のページの区切りの左右だけで、それより大きい余白は使わない。
- 一覧のグリッドは2列まで。スマホは1列、768px から 1単位の列を2つ。横の溝 `space-4`、縦の溝 `space-6`。
- 本文の1単位は 335px（`width-column`。iPhone SE の本文の幅）。表と図は1単位か2単位に収める。スマホでは列を画面いっぱいにし、768px からはこの幅の列を並べる。計算のページの2列の区切りは「ツール画面の約束」。一覧の2列は `space-4` の溝（ADR site-0006、ADR site-0007）。
- 切り替わる幅は 768px（`md`）と 1024px（`lg`）の2つだけ。768px から `display`・`title`・`figure`・`prose` を約 1.2 倍にする（36 / 26 / 64 / 17px）。1つの役割の大きさは2つまで。ほかの文字はどの幅でも同じ。
- 本文は中央に寄せ、最大幅は2単位（本文の箱は2列と区切りの線と左右の空き。iPad 703px `max-w-page`、PC 831px `lg:max-w-page-lg`。1単位と `gap` から導く）。
- 角は `radius-0` が既定。`radius-8` はボタンとツールの入力カードだけ。
- 影、グラデーション、ぼかし、トランジションは使わない。

## シェル

- 画面はヘッダーと本文に分ける。ヘッダーは上に固定し、スクロールするのは本文だけ。ヘッダーの高さは `space-8`、下に `line`（ADR site-0014）。
- ヘッダーはページ左右の余白の内側いっぱいに広げる。左にメニューのボタン、サイト名（`wordmark`）、今いる住所（パンくず。iPad・PC だけ）、右にライトとダークの切り替え・アカウント。ページ名と四部のボタンは置かない。本文の箱とヘッダーの端はそろわない。
- スマホではサイト名を `rustruct` だけにする。四部へはメニューから行く。ライトとダークの切り替えとアカウントはスマホでもヘッダーに置く。
- パンくずは `wordmark` の右に `space-4` 空けて置き、`wordmark` と同じ等幅の 400 で書く。親の段は `muted` でそのページへのリンク、今いる段は `ink` でリンクにしない。トップと not-found には出さない。
- ページの見出し（`title`）と内容の間は `space-7`。本文の頭にパスは置かない。
- メニューのボタンはどの幅でも出す。メニューは左から出すパネルで、本文とヘッダーに `scrim` の幕を掛ける。パネルはヘッダーの高さの行から始まり、その行の右端に閉じるボタン。スマホは画面の幅いっぱい、iPad・PC は1単位と左右の余白の幅で、本文との境に `line`。
- メニューは Esc・幕を押す・閉じるボタン・項目を選ぶ、で閉じる。振る舞いは `dioxus-primitives` の dialog と collapsible（ADR site-0008）。開け閉めに動きは付けない。
- メニューの中身は住所の木。四部とその下のページを、ページの見出しと右に住所で並べ、下の段は `space-5` 字下げする。行の上下は `space-2`。深さはページまで（ページの中の表や式の見出しは出さない）。段も枝もルーターの住所一覧から導く。枝は見出しの右のボタンで開け閉めし、開いたときは今いるページまでの枝が開いている。今いるページの見出しに `accent` の下線。
- ライトとダークは、初めは OS の設定どおり。押すたびに入れ替わり、選んだほうをブラウザに覚える。一度押すと OS に従う状態には戻らない。覚えた色は `<head>` の小さなスクリプトで描く前に当てる。
- アカウントのボタンは、ログインの仕組み（ADR site-0002）ができるまで、押すと「登録は準備中」と出す。一言はボタンの下に重ねて出し、ヘッダーの並びを動かさない。

## ツール画面の約束

- 計算のページは入力の組（`GLOSSARY.md`）から始め、入力 → 結果 → 根拠 の順に置く。「入力」「結果」「根拠」という部の見出しと区切りは置かず、表や式の見出しで区切る。iPad・PC では「入力＋結果」の列と「根拠」の列の2列（ADR site-0006）。
- 「入力＋結果」の列と、入力に依らない表や式の列の間には `line` の区切りを引く。区切りは列の外の独立した要素で、iPad・PC では縦の線、スマホでは横の線。線の左右の空きは並べる親の `gap` で、iPad `space-4`、PC `space-9`。スマホの区切りの上下は `space-8`。
- 入力はデータテーブルではなくスプレッドシート（`Sheet`）。格子は `line`、選択セルは `ink` の 2px 内枠。入力セルは大きく、表示用の表は小さく。
- 入力の組は Sheet → 注記 → 読めない欄の理由 → 警告 の順で、間は `space-1`。組と最初の結果の表の間は `space-6`（ADR site-0015）。
- 欄の種類は数値・文字・チェック・選択の4つ。Sheet は行見出し（左に見出し、右に欄。1行に1欄か2組）か列見出し（上に見出しの行、下に値の行）のどちらか。欄の `aria-label` は欄の名前。
- チェックと選択の欄、分布図の量の切替の振る舞いは `dioxus-primitives` の checkbox・select・toggle_group（ADR site-0008、ADR site-0017）。欄はどれもセルいっぱいの押せる器で、フォーカスは書けるセルと同じ `ink` の 2px 内枠。
  - チェックの欄は、セルの左に `size-4` の箱（`paper` の地に `line-strong` の枠）。オンで箱を `ink` で塗り、`paper` の印（`checkmark`）を出す。セルのどこを押しても切り替わる。
  - 選択の欄は、選んだ名前を左に、開く印（`chevron--down`）を右に置く。名前の左の空きは数値と文字の欄と同じ `px-2`。収まらない名前は折り返さずに切る。開くとセルの真下に選択肢の一覧を重ねる（`paper` の地に `line` の枠、角は `radius-0`）。選んだ選択肢は `ink` で塗る。閉じるとフォーカスは欄に戻る。
  - 量の切替は、押されているものをもう一度押しても外さない（いつも 1 つが押されている）。Tab では組に 1 度だけ止まり、組の中は左右の矢印で移る。フォーカスの内枠は Tab で来たときだけ出し、押されて `ink` で塗ったものの上では `paper`。
- 欄の並べ方と定義（名前・種類・空欄を受けるか・初期値）はページが宣言し、描画と読み取りは1つの部品（`crates/rustruct-web/src/inputs.rs`）が持つ。空欄の規則はページ、値の規則（0 や負を受けるか）は計算核の入口が持つ。
- 計算核の入口は不正な欄をすべて返し、その理由の文言（「0 より大きい値を入れる」など。欄の名前を含めない）をページが欄に写す。読めない欄は初期値で埋めて入口を呼び、読めない欄と不正な欄をいっぺんに出す。
- 入力値を変えた瞬間に派生値を更新する。重い解析は即時でなくてよい。全画面を描き直さず、変わった所だけ更新する（行を1つ足すときも）。
- 枠のある器は入力にだけ使う。読み取り専用の入力欄は使わない。計算結果は表示用の表と同じ横罫の表に `num` で、入力のすぐ下に置く（ADR site-0006）。
- ページの答えが1つに絞れるときは `figure`（56px）で1つだけ大きく置く。
- 使える入力の部品は、テキスト入力、チェックボックス、コンボボックス（打ち込みもできる）。
- 使えない状態は塗りを変えず、線と文字だけ薄くし、理由を添える。使えない項目は隠さない。
- Excel とは値のコピーと貼り付けができれば足りる。

## エラーと警告

- 読めない欄は、その欄のある Sheet のすぐ下に「欄の名前: 理由」（「Lx（m）: 値を入れる」）を `ng` の `label` で欄の順に並べる。件数は出さない（ADR site-0015）。
- セルのエラーは `ng` の 2px 枠。計算できないセルは値を消して「—」。
- 入力部品のエラーは枠・ラベル・文言の3つを `ng` にする。
- 警告（計算はできる）は色を使わず「!」と文言だけ。

## 状態

- 状態（エラー、開いているか、押されているか、今いるページ）で見た目が変わる要素は、状態を要素の属性に持ち、クラスは 1 本の文字で書く。状態の差分だけを variant で書く（`text-muted error:text-ng`、`bg-paper aria-pressed:bg-ink`）（ADR site-0016）。
- 属性は、合う ARIA があればそれを使い、Tailwind 組み込みの variant で書く（入力欄のエラーは `aria-invalid` と `aria-invalid:`、量の切替は `aria-pressed` と `aria-pressed:`、選択の欄の選んだ選択肢は `aria-selected:`）。部品が既に出す属性があれば、それから導く（メニューの枝の開閉は collapsible のトリガーの `aria-expanded`、チェックの欄のオンは checkbox の `aria-checked`）。
- 組み込みの variant が無い状態は `theme.css` の `@custom-variant` で書く。ARIA の無い要素（Sheet の見出し）のエラーは `data-state="error"` と `error:`、今いるページは `aria-current="page"` と `here:`。
- 属性を持つ要素と見た目を変える要素が違うときは、属性を持つ要素に `group` を付け、中の要素に `group-*:` で書く（メニューの枝の矢印は `group-aria-expanded:rotate-0`、今いるページの見出しは `group-here:underline`、チェックの欄の箱の塗りは `group-aria-checked:bg-ink`）。
- `@custom-variant` の名前は Tailwind 組み込みの variant とぶつけない。任意値の variant（`data-[state=error]:` など）は使わない。
- 状態でクラスの文字を選ぶ `if` と、クラスを変数に束ねる形は書かない。状態でない性質（数値の欄か文字の欄か）で変わる部分は、同じ要素に `class:` を 2 つ書き、共通の部分と、違う部分だけを選ぶ `class: if … { "…" } else { "…" }` に分ける（Dioxus がつないで出す）。部品が受けた `class` は `class: "{class}"` でそのまま渡す。拾えない形は `scripts/check-classes.sh` が落とす。

## 表

- 表示用の表は横罫だけ。見出しの下と各行の下に `line`、縦罫・塗り・交互の背景は使わない。`ink` の線は部の見出しの上だけ（ADR site-0006）。
- 行の上下は `space-2`、セルの左右は `space-3`、表の端の列は端に寄せる。列見出しは `label` の `muted`。先頭の列は左、数値の列は `num` で右揃え、式の列は `num` で左揃え。
- 単位の違う値を並べる結果は、値ごとに列を立てて見出しに単位を書く。入力欄の名前と入力の Sheet の見出しも同じ（「Fc（N/mm²）」「B（mm）」）。
- 列見出しは折り返さず、改行は `br` で意味の切れ目に置く。数値の列の2行の見出しは、行どうしを左で揃えてまとまりを列の右に寄せる。並ぶ1行の見出しは上下の中央。
- 同じ区分が続く列は、列をまとめる見出し（「長期」「短期」）にまとめる。またがる列の中央に置き、下に `line`。線はまとまりごとに `space-3` 離す。
- 括弧書きを添える値（「215（*195）」）は、括弧書きを隣の列に分け、括弧の外の数値をほかの行の数値と揃える。
- 小数の桁数が行で違う列は、小数点の位置を縦に揃える。足りない桁（と小数点）を数字幅の空白（U+2007）で右に埋め、読み上げから外す（`aria-hidden`）。
- 式の列の min(A, B) は「,」の後で改行し、B を A の下に揃える（「min(」の右に A と B を縦に積む）。式が2行になる行の名前は、括弧書きの前で改行する（「付着」「（上端筋）」）。
- 表や式の名前は上に `heading` で置く。見出しと見出しの間は `space-7`。名前は内容が分かるものにし、規準の表を写すならその表の名前にする。
- 注記は下に `label` の `muted` の箇条で、1つの事柄に1つの箇条。出典は画面に出さない（コードのコメントと ADR に書く）。
- 画面に出す値は計算に使うものだけ（コンクリートの単位体積重量は E の式で使う γ だけ）。
- 1単位に入りきらない表は、その表だけ横にスクロールする。
- 入力で値が変わる表は、列の幅を中身で変えない（`Table` の `fixed`。すべての列を等分する）。1単位に値の列は3つまで。
- 一つの量の最大とその位置は、値と座標を同じ表の1行に並べる。

## 数

- 表と図に書く数は `numerus` が書く（ADR site-0013）。等幅で書き、列では小数点の位置を揃える。
- 0.001 ≦ |x| < 1,000,000 は小数で書く。整数部は3桁ごとに「,」（999,999）、小数部は区切らない（0.00123）。
- その外は E（1.23E+06、-1.52E-06）。仮数の桁は小数で書くときと同じ、指数は2桁で符号つき。小数か E かは丸めた後の値で決める。E の数も仮数の小数点で列に揃える。
- 桁の大きさは E で値に書き、見出しは単位だけ（「E（N/mm²）」に「2.27E+04」）。×10ⁿ と上付きの文字は使わず、10ⁿ を見出しや凡例に移さない。範囲によらず E で書く値は `exponential` が書く。
- 計算の誤差の値も 0 にしない。負号は「-」（等値線の数値も同じ）。

## 分布図と等厚曲線の図

- 帯の色は、正負のない量（たわみ）が `seq`、正負のある量（曲げモーメント、せん断力）が `div`（ADR site-0011）。
- 帯の境は、刻みを 1・2・2.5・5 × 10ⁿ に丸めて決める。段数の目安の既定は、たわみ 10、曲げモーメントとせん断力 16。12 段を超えるときも 12 色の間を補間して取る。
- 等値線は `ink` 0.25px（0 の線も同じ）。
- 線の上の数値は IBM Plex Mono の 9px、`ink`、縁は `paper` 2.5px の白抜き。線の向きに沿って傾け、上下が逆にならないように ±90° に収める。
- 数値の位置は、板の中心から四辺の中点へ引いた案内線（描かない）と等値線の交点。ぶつかる数値は中心に近い方を残す。案内線と交わらない線には数値を付けない。
- 板の分布図の縁は支持条件を示す。固定は `ink` 1px の辺の線と外側の 45° の短い斜線（0.5px）、単純支持は辺の線だけ、自由は線を引かない。図の下に読み方の注記を置き、読み上げ用に図の名前にも辺ごとの支持条件を書く。
- 図は計算のページの「入力＋結果」の列の右（スマホでは下）に、区切りの線なしで置く。縦横比どおりに1単位の正方形に収める。上に図の名前（「たわみ w（mm）」）と量の切替（押されたものを `ink` で塗る）。Kirchhoff 板の切替は w・Mx・My・Qx・Qy の5つで、既定はたわみ。
- 等厚曲線の図（必要スラブ厚さ）は分布図にそろえる（ADR slab-thickness-0002）。横軸 Lx、縦軸 Ly で、描く範囲は正方形。軸の名前は入力の欄と同じ「Lx（m）」「Ly（m）」を 11px の `muted` で書き、縦軸は回して置く。
- 等厚曲線の帯は `seq`。曲線は 10 mm ごとに `ink` 0.25px、色は 20 mm ごとの段。80 mm 未満は塗らないが、曲線は引いて数値を付ける（2026-11-06、#106）。
- 曲線の厚さの数値は分布図と同じ白抜きで、範囲の左下から右上への対角線との交点に並べる。ぶつかるときは色の変わり目の曲線を先に残す。交点が検討点の印・名前・条件の要約にかかるか枠からはみ出すときは、同じ曲線の上を交点に近い順にたどって置ける所に置き、どこにも置けなければその曲線の数値を出さない。
- 検討点は `paper` 塗り・`ink` 1px 縁の小さな丸と、右上に名称（11px の `ink`、`paper` の縁の白抜き）。`accent` は使わない。
- 左上に条件の要約を2行（「Fc=24　wp=2,800」「α=16　δ/lx≤1/400」）。11px の `ink` の白抜き。有効なクライテリアだけを載せ、単位は書かない。
- 等厚曲線の図の上に図の名前「必要スラブ厚の等厚曲線（mm）」、下に読み方の注記。条件が読めない間やクライテリアが無いときは、図を描かずに注記だけ。検討点の Lx・Ly だけが読めないときは、両軸 3〜9 m の範囲に印を置かずに描く。

## 図とアイコン

- Studies の図版は計算で描いた SVG。線は `ink` の細線（0.25〜0.5px 相当）、下地は `fill`。塗るときは藍（`accent`）と青碧（`chart-2`）の組だけを使う。
- アイコンは基本使わない。状態は `radius-full` の小さな点と文言で示す。ヘッダーのボタン（メニュー、ライトとダークの切り替え、アカウント）、メニューの枝の開け閉め、Sheet の選択とチェックの欄の印だけはアイコンを使う。IBM の Carbon（`@carbon/icons`、Apache-2.0）の `menu`・`close`・`light`・`asleep`・`user` を、`size-5` で文字の色のまま置く。path はコードに写して埋める（`crates/rustruct-web/src/icons.rs`）。メニューの枝の開け閉めは `chevron--down` を `size-4` の `muted` で置き、閉じた枝は右に回す。選択の欄の開く印も同じ `chevron--down` の `size-4` の `muted` で、回さない。チェックの欄のオンの印は `checkmark` を `size-3` の `paper` で、`ink` の箱の中に置く。
- ロゴはない。サイト名はいつも `wordmark` の文字で組む。
