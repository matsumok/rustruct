# スパンは内法で統一し、板の解析に渡すときは支える辺を内法の位置に取る

スラブの x方向スパン (Lx) と y方向スパン (Ly) は、どの RC スラブの Tool でも内法スパン（支える梁や壁の面から面まで）とする（2026-10-22、本人が決めた）。必要スラブ厚さがすでにこの定義で、それを共有の定義にした。スラブ設計が Kirchhoff 板の計算核で板を解くときは、内法スパンをそのまま板の辺長（Kirchhoff 板の Lx・Ly）として渡し、固定と単純支持の辺を内法の位置（梁や壁の面）に置く。

支える部材の中心線の間の距離を取る案も比べた。単純支持の板の解析では中心線を使う流儀もあるが、固定辺では、拘束が効くのは梁や壁の面であり、内法のほうが実際に近い。Tool ごとに内法と中心線を使い分けると、同じ Lx が Tool によって違う長さを指し、受け渡しで食い違う。中心線の値しか手元に無いときは、利用者が梁や壁の幅を引いて入れる。

Kirchhoff 板の辺長は材料にも部材にも依らない「板の辺の間の距離」で、内法か中心線かを言わない。どちらを渡すかは、使う側（RC スラブならこの ADR）が決める。
