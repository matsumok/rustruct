# スラブ

RC スラブの Tool（必要スラブ厚さ・スラブ設計）が共有する、長方形のスラブの形の言葉。荷重・検討点・結果の量は Tool ごとに意味も求め方も違うので、ここには置かず各 Tool の GLOSSARY で定義する。辺・支持条件・板の座標は、板の解析を受け持つ Kirchhoff 板（`docs/tools/kirchhoff-plate/GLOSSARY.md`）の言葉を使う。サイト全体の言葉は `GLOSSARY.md`、コンクリートの言葉は `docs/materials/GLOSSARY.md` に従う。

## Language

**x方向スパン (Lx)**:
スラブの x 方向の内法スパン。短辺・長辺のどちらであるかは問わない。単位 m。
_Avoid_: 短辺スパン（入力値の意味としては使わない）

**y方向スパン (Ly)**:
スラブの y 方向の内法スパン。短辺・長辺のどちらであるかは問わない。単位 m。
_Avoid_: 長辺スパン（入力値の意味としては使わない）

**短辺スパン (lx)**:
min(Lx, Ly)。

**長辺スパン (ly)**:
max(Lx, Ly)。

**辺長比 (λ)**:
ly / lx。常に 1 以上。

**スラブ厚 (t)**:
スラブの厚さ。全面で一様とする。単位 mm。
_Avoid_: 版厚
