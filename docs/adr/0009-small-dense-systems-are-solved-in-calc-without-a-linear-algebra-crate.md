# 小さな連立一次方程式は rustruct-calc の中の LU 分解で解き、線形代数のクレートを入れない

`rustruct-calc` で連立一次方程式を解くときは、計算核の中に置いた部分ピボット付きの LU 分解（Gauss の消去法）で解き、nalgebra などの線形代数のクレートを依存に足さない（2026-10-22）。最初の使い手は Kirchhoff 板の曲げの級数解で、未知の係数は辺ごとの級数の項数の数倍、大きくても 100 元に届かない密な行列になる。

この大きさなら、消去法は数十行で書け、計算も WASM で 1 ms に届かない。線形代数のクレートが与えるもの（大きな行列の速い分解、疎行列、条件数の推定、固有値）は、いまの使い手には要らない。一方で、足すと `docs/stack.md` のクレート表と `scripts/check-deps.sh`（計算核の直接の依存は `rustruct-types` だけ）を直すことになり、依存の木と WASM が大きくなる。nalgebra は行列の大きさを型に持つ形があり、ADR-0004 で uom を退けたのと同じく、型エラーが読みにくい。

解けない（ピボットが 0 か極めて小さい）ときは、計算のエラーとして返す。支持の足りない板は手前で弾くので、ここに来るのは式か項数の取り方の誤り。

地震応答の固有値解析のように、大きな行列や固有値が要る使い手が出たら、そのときに自前で書くか依存を足すかを比べ直し、この ADR と stack.md を同じ変更で直す。

## 有限要素の帯行列も自前の Cholesky 分解で解く（2026-10-23、本人が決めた）

Kirchhoff 板を有限要素で解くことにし（`docs/tools/kirchhoff-plate/adr/0002`）、連立は数千元の対称正定値の帯行列になった。線形代数のクレートを入れるか比べ直し、入れないと決めた。計算核の帯行列の Cholesky 分解（`crates/rustruct-calc/src/kirchhoff_plate/band.rs`、約 100 行）のまま進める。

比べたのは faer 0.24（疎行列の Cholesky、`sparse-linalg` feature）と nalgebra 0.35 + nalgebra-sparse 0.12（`CscCholesky`）。同じ剛性行列を 3 つで解き、解は丸め誤差で一致した。測ったもの（未知数 2 千〜7 千、半帯幅約 100、四辺固定と四辺単純支持、縦横比 1 と 4）:

| | 自前の帯行列 | faer | nalgebra-sparse |
|---|---|---|---|
| 解く時間（ネイティブ、縦横比 4 の四辺固定） | 10 ms | 21 ms | 68 ms |
| 解く時間（WASM、同じ板、wasm-opt -O3） | 15 ms | 29 ms | 67 ms |
| 計算核だけの WASM（wasm-opt -Oz） | 36 KB | 241 KB | 74 KB |
| clean の release ビルド（rustruct-calc） | 4.6 s | 50 s | 14.5 s |
| 依存の木のクレート数 | 14 | 51 | 28 |

この大きさと帯の狭さでは自前の分解が最も速く最も小さい。faer は SIMD（v128）を出すので、dx の wasm-opt に `--enable-simd` を渡す設定（`Dioxus.toml` の `[web.wasm_opt] extra_features`）も要る。クレートが効くのは、節点の番号付けで帯が狭くできない不規則なメッシュ（並べ替えつきの疎行列の分解）や、固有値（振動・座屈・地震応答）が要るときで、その使い手が出たら faer を第一候補にこの表を測り直す。

解けない（対角が正でなくなる）ときは、LU と同じく計算のエラーとして返す。
