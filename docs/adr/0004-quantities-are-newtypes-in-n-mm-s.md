# 物理量は自作の newtype で持ち、内部は N・mm・s に揃える

`rustruct-types` に `Length`・`Stress`・`Force` などの物理量の newtype を自作する。中身は N・mm・s の系に正規化した `f64` とし、作るときと取り出すときに単位を名前で言う（`Stress::n_per_mm2(24.0)`、`.as_mm()`）。この系では質量の単位が t になるので、剛性 N/mm と質量 t から ω² = k/m が係数なしで求まる。入力と表示の単位は Tool・値ごとに自由に決め、内部の系とは切り離す。型は使う Tool が出てから、要る分だけ足す。

`uom` クレートも検討した。次元解析はコンパイル時に完全になるが、型が重く、エラーが読みにくく、依存と WASM のサイズが増える。計算式をレビューで読みやすく保つため、式の中では `f64` に落として書けるほうを選んだ。`f64` のまま単位系を規約で一本化する案は、守るのが人になるので退けた（2026-07 の試作では Tool ごとに単位の流儀が分かれた）。単位を型パラメータに持たせる案（`Length<M>`）は、Tool をまたいで値を渡すたびに変換が要るので退けた。

保存 JSON には内部の系の数がそのまま出る。最初の保存形式 v1 を出す一本の前に、この系でよいかをもう一度見直す。
