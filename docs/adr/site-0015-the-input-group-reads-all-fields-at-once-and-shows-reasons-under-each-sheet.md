# 入力の組は欄の定義を宣言して 1 つの部品で読み、読めない欄と不正な欄を Sheet の下にいっぺんに出す

計算のページの入力の組（`GLOSSARY.md`）の形と、エラーと警告の出し方を次のように決めた（2026-11-03、入力の組の設計で本人が決めた。#79・#85）。今の規則は `docs/design/README.md` の「ツール画面の約束」と「エラーと警告」。

## 決めたこと

- **入力の組は Sheet → 注記 → 読めない欄の理由 → 警告 の順**で、間は `space-1`。組と最初の結果の表の間は `space-6`
- **欄の種類は数値・文字・チェック・選択の 4 つ**。Sheet は行見出し（左に見出し、右に欄。1 行に 1 欄か 2 組）か列見出し（上に見出しの行、下に値の行）のどちらか
- **並べ方と欄の定義（名前・種類・空欄を受けるか・初期値）はページが宣言し、描画と読み取りは 1 つの部品が持つ**（`crates/rustruct-web/src/inputs.rs`、#79）。欄の `aria-label` は欄の名前
- **空欄の規則はページ、値の規則（0 や負を受けるか）は計算核の入口が持つ**（#85）。値の規則は計算の前提条件なので、計算核の 1 か所に置く。入口は不正な欄をすべて返し、理由の文言（「0 より大きい値を入れる」など。欄の名前を含めない）をページが欄に写す
- **読めない欄は初期値で埋めて入口を呼び、読めない欄と不正な欄をいっぺんに出す**
- **読めない欄の理由は、その欄のある Sheet のすぐ下に「欄の名前: 理由」を欄の順に並べ、件数は出さない**。8 月は「ページの先頭に件数と場所のまとめ」としていたが、Sheet が 2 つあるページで、理由が原因の隣に出るほうを選んだ
- 読み取りの検査に crate は入れない。文字の規則が 4 つで、文言は短い日本語のため
- 8 月から引き継いだ形はそのまま: セルのエラーは `ng` の 2px 枠、計算できないセルは値を消して「—」、入力部品のエラーは枠・ラベル・文言の 3 つが `ng`、警告（計算はできる）は色を使わず「!」と文言だけ
