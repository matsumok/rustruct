# 入力地震動はv1では同梱の標準波形セットのみ、アップロード機構は作らない

入力地震動(既往3波程度の標準波形、0.02秒刻み・60秒・1波あたり約3,000点)は、フォント資産と同様にアプリケーションに同梱する固定データとして扱う。DBやファイルストレージに波形をユーザー登録・アップロードする仕組みはv1では作らない。解析設定は、この同梱データから波形を参照(名前/IDで指定)し、実際に使った波形の参照と減衰hをCalcResultに埋め込んで保存する。

理由: 実際のデータ規模(1波形24KB程度、既往3波が中心)は「巨大データはファイルへ」という原則を要するほど大きくなく、また波形自体がほぼ固定の少数セットであるため、DB上の波形カタログや独自波形アップロード機能はテスト段階ではオーバースコープ。独自波形が必要になった時点で、アップロード・保存の仕組みを別途設計する。
