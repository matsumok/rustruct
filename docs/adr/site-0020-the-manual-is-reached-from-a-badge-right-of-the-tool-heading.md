# Tool のページから説明書へは、見出しの右のバッジで移る

Tool のページには説明書（`GLOSSARY.md`）を付け、ページの見出しの右に置いたバッジから移る（2026-11-25、本人が決めた。#148）。Tool のページすべてから定式化を確かめられるようにするため。説明書の本文の仕組みは ADR site-0019、今の規則は `docs/design/README.md` の「ツール画面の約束」と「余白と形」（`radius-8`）。

## 決めたこと

- **説明書の住所は `/tools/<Tool>/manual`。** `/tools` の一覧には出さず、メニューの木では Tool の一段下に出る（住所から導く）
- **バッジは見出しの右。** 文言は「説明書」、文字は 11px（`label`）の `ink`。囲みはボタンと同じ `line-strong` 1px の枠と `radius-8`。見出しと同じ行で、見出しの文字の並び（baseline）に揃え、間は `space-3`。見出しが折り返すスマホの幅でも見出しの後に続き、見出しの下に回り込んでも崩れない
- **要素は `<a>` で、`aria-label` は説明書のページの見出し**（「Kirchhoff 板の曲げの説明書」）。バッジの文言だけでは何の説明書か読み上げで分からないため

## 理由

リンクをボタンの見た目にしたのは、角の丸い枠が押せるものの印だから（`radius-8` はボタンと入力カードだけ）。書ける欄の角の無い枠（`paper` の地に `line-strong`）とも、書けない欄の塗り（`fill`）とも紛れない。見出しの横の文字だけのリンクは、見出しの一部に読める。

## 経緯

#148 の初めの本文では、見出しのすぐ下に一覧と同じ形（名前「説明書」と住所）の 1 行を置くとしていた。同じ日に本人が見出しの右のバッジに改めた。
