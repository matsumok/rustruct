# 指した点は十字線で示し、点の値は図の下の 1 行に書く

分布図（Kirchhoff 板）と等厚曲線の図（必要スラブ厚さ）で、図の上の点を指すとその点の値を出す（2026-11-25）。言葉は `crates/charta/GLOSSARY.md`、charta の側は ADR charta-0001。今の規則は `docs/design/README.md` の「分布図と等厚曲線の図」。

## 決めたこと

- **値は計算核から出す。** 板は解の点の値、必要スラブ厚さは検査を通った条件をその Lx・Ly で計算した値。結果の表の値と一致する
- **PC はホバーで追い、クリック・タップで止める。** PC はマウスを追い、図の外へ出ると消える。クリックでその点に止め、止めている間はホバーで動かさない。止めた後にもう一度押すと外れる。スマホはタップで止め、もう一度のタップで外れる。点を移すには 2 回押す。図の上でもページは縦に動かせる
- **指した点は、描く範囲を横切る `ink` 0.5px の十字線で示す。** 軸の目盛りと照らしやすく、検討点の丸と混ざらない。`accent` は使わない
- **点の値は図と注記の間の 1 行。** 板は x・y と図にしている量、必要スラブ厚さは Lx・Ly と必要スラブ厚。計算核が値を出せない点は「—」。何も指していないときは「図を指すとその点の値を出す」を `muted` で書く。行の場所はいつも空けておき、図の下がずれない
- **入力や量の切替を変えても、指した点を保つ。** 同じデータの点で値を出し直す。範囲の外に出たら消す
- **キーボードでは指せない。** 図は `role="img"` のまま。キーボードで指すのは、拡大と連動の段でまとめて考える

## 理由

スマホでは図が画面の幅いっぱいなので、なぞって追うと図の上でページが動かせなくなる。値を点のそばに重ねると指の下に隠れ、端では寄せ方が要る。図の下の決まった 1 行なら、どの幅でも同じ所で読め、図の中身を隠さない。格子から補間した値は、隣の結果の表の最大値と食い違うことがある。

## 残ること

- WASM が起きるまでは指せない。SSG の HTML には読み方の文だけが入り、起動後も同じ文なので hydration はずれない
