# シェルは上に固定したヘッダーと左から出すメニューにし、今いる場所はパンくずと住所の木で示す

シェル（`GLOSSARY.md`）の組み方を、#23（2026-10-15）と #28（2026-10-16）で本人と撮り比べながら次のように決めた。画面幅ごとの組み方は ADR site-0007、部品の振る舞いは ADR site-0008。今の規則は `docs/design/README.md` の「シェル」。

## 決めたこと

- **ヘッダーはサイト名とボタンだけ**。左にメニューのボタンとサイト名、右にライトとダークの切り替えとアカウント。ページ名と四部のボタンは置かない
- **スマホではサイト名を `rustruct` だけに縮め、四部だけをメニューにしまう**。切り替えとアカウントはヘッダーに残す。メニューのボタンはサイト名の左。ロゴは作らない
- **ヘッダーのボタンとメニューの枝の開け閉めにはアイコンを使う**。IBM の Carbon（`@carbon/icons`、Apache-2.0。書体の IBM Plex と同じ IBM）の path を `crates/rustruct-web/src/icons.rs` に写して埋める。ほかの所の「アイコンは基本使わない」は残す
- **トップの一文は `rustruct.matsumok.com`**（「構造を計算し、かたちを眺める。」をやめた）。スマホのヘッダーが `rustruct` だけでも、トップでは住所が全部見える。句点の `accent` は使う場所が無くなった
- **ライトとダークは押すたびに入れ替え、選んだほうを覚える**。初めは OS の設定どおりで、一度押すと OS に従う状態には戻らない。覚えた色は `<head>` の小さなスクリプトで描く前に当てる。HTML は WASM より先に描かれるので、無いと開くたびに一瞬 OS の色が出る
- **アカウントのボタンは形だけ先に置く**。ログインの仕組み（ADR site-0002）ができるまでは、押すと「登録は準備中」と出す。位置とアイコンを先に決めておけば、後で中身を置き換えてもヘッダーの並びは変わらない
- **今いる場所は、iPad・PC ではヘッダーのパンくず、スマホではメニューの住所の木で示す**（#28）。パンくずは wordmark の右に `space-4` 空けて英語の住所（`/data/concrete`）を置く。トップと not-found には出さない（not-found はどの住所でも同じ 1 ファイル。ADR site-0001）。それまで本文の見出しの上に伸ばしていた住所は、ヘッダーと重なるので消した
- **メニューは左から出すパネルにし、本文とヘッダーに `scrim` の幕を掛ける**（2026-10-16、本人の指示）。どの幅でも出す。パネルはヘッダーの高さの行から始まり、その行の右端に閉じるボタン。中身は住所の木で、段も枝もルーターの住所一覧から導く。振る舞いは `dioxus-primitives` の dialog と collapsible

## 退けた案

- ヘッダーの右にページ名、中央に四部のボタン（#23 で作った）。ページ名は本人が頼んでいなかった
- スマホで切り替え・アカウント・四部の三つともメニューにしまう（初めにそう書いたが、本人の想定と違っていた）
- ライトとダークの切り替えで、OS・ライト・ダークの3つを巡る形。押しても色が変わらない一押しができる
- 選んだ色を覚えない形。読み込み直すたびに OS の色に戻る
- アカウントのボタンを置かない形と、`/root/` への入口にする形（今は本人しか通れない）
- パンくずを `Data › Concrete` のような段の形にする案と、wordmark に空きなしで続ける案。空きは 12・16・20 を撮り比べて本人が 16 に決めた
- メニューを開いたとき、ヘッダーの下をまるごと `paper` で覆う形（全画面を覆って見えた）と、幕を掛けず線だけで分ける形（本人が退けた）
- ヘッダーから中身の高さだけ垂れる板。境が線 1 本で本文が透けて見える。左から引き出す形は、本文との境に暗い幕か影が要るので 2026-10-15 には候補にしなかったが、2026-10-16 に幕を足してこの形にした
- 閉じるボタンをヘッダーのメニューのボタンと同じ左の位置に置く形（初めはそうした。本人の指示で右端へ）
- メニューの行の上下を `space-3` にする形。間延びして見えた（本人の指摘で `space-2`）
