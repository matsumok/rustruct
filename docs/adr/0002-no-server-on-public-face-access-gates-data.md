# 公開面にサーバーを置かず、認証は Cloudflare Access だけで行い、制限はデータに掛ける

サイトは Cloudflare 上の静的アセット（HTML + WASM）だけで動き、計算はすべてブラウザ内で完結する。アプリにログイン画面・セッション管理・ユーザーテーブルは持たない。2026-05 に認証と DB の自作で消耗した経験と、「誰でも書き込める経路を自宅のサーバーまで届かせない」という原則による。

登録者向けの機能制限は、コードではなくデータに掛ける。Tool のコードは全員に配るが、既往波や継手諸元などの限定データは `/private/` 配下の静的ファイルとして置き、そのパスだけを Cloudflare Access で守る。登録は Access の「Everyone + メールのワンタイム PIN」ポリシーで誰でもでき、root は別ポリシーの許可リストで区別する。Tool は実行時に限定データを fetch し、未ログインなら「ログインすると使えます」と示す。コードを隠す必要があれば、その Tool のデータを隠せば足りる、という整理。

リポジトリは公開なので、限定データは別の非公開リポジトリに置き、CI がデプロイキーで取得してアセットに同梱する。Access の無料枠は 50 ユーザーまでで、超える見込みが出た時点で自前認証（Rust の Worker + OAuth + D1）を検討する。サーバー保存や知らない人向けの保存は作らない。必要になったとき、この ADR を改めて書き直す。
