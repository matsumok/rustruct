# 全ページを Dioxus の SSG でプリレンダーし、hydration する

Note を検索エンジンに載せたいので、空の HTML に WASM を載せるだけの CSR は選べない。候補は2つあった。(A) Dioxus fullstack の SSG で全ページをビルド時に HTML 化し、ブラウザで同じ WASM が hydration する。(B) Note と Study は `dioxus-ssr` で静的 HTML に書き出し（hydration なし）、Tool だけ CSR にして、Study の対話部分は静的ページの空き地に WASM をマウントする「島」として手作りする。

(A) を採る。理由は、Study を対話的にしたいこと、セクションをまたぐ遷移も SPA のままにしたいこと、レイアウト・型・ルーターが1系統で済むこと。代償として hydration の不一致という実行時エラーの種を抱える。ブラウザでしか決まらない値（localStorage、画面幅、時刻など）は初回描画では読まず、起動後に `use_effect` で読んで更新する、という規則で防ぐ。

(B) は「静的なものは本当に静的で壊れようがない」点で哲学（不変条件は構造で守る）に近かったが、島と本文の間で状態を共有できず、Study の作り方が Tool と二系統になる点で退けた。SSG が実際に通るかは最初の一本（ナビと空ページだけの骨組み）で確かめ、通らなければ (B) に落とす。
