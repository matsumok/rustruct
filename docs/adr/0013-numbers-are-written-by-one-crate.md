# 数の書き方は numerus クレートにまとめ、0.001 ≦ |x| < 1,000,000 を小数で書く

サイトの表と分布図に書く数は、すべて `numerus` クレートを通す（2026-10-30、本人が決めた。#71）。それまでは `rustruct-web` の `table.rs`（有効数字、3 桁区切り、小数点揃え、小さい値の E）、各ページの `format!("{:.1}")`、`charta` の等値線の数値（負号は U+2212）に分かれていた。

## 決めたこと

- **等幅のフォントが前提**。有効数字の桁をそろえ、列では小数点の位置を揃える
- **0.001 ≦ |x| < 1,000,000 は小数で書く**。整数部は 6 桁まで、3 桁ごとに「,」（999,999）。小数部は区切らない（0.00123）。両端の 123,000 と 0.00123 が、字数として読める上限
- **外は E**（1.23E+06、-1.52E-06）。仮数の桁は小数で書くときと同じ。指数は表計算と同じ 2 桁で、符号を付ける。E は表計算に貼っても数として読める
- 小数か E かは**丸めた後の値**で決める。999,999.6 を有効数字 6 桁にすると 1,000,000 になるので「1.00000E+06」、0.00099996 を 3 桁にすると「0.00100」
- 丸めは四捨五入。2 進の誤差を落としてから丸める（3.465 は「3.47」）。それまでの `format!("{:.2}")` は偶数への丸めで、0.625 が「0.62」になっていた。これも「0.63」にそろえる
- 0 は負号を付けない。有効数字で書く 0 は「0」、小数の桁で書く 0 は「0.00」のように桁を並べる
- 書き方は 3 つの入口に分ける: 有効数字（`significant`）、小数の桁（`fixed`。規準の表の桁をそのまま写す値）、末位の位（`at_place`。等値線の数値は刻みの位）。どれも末位の位で丸めた整数の数字の並びから書くので、範囲と E の決めは同じになる
- **列の小数点揃え**は、列の値の並びから右の埋め（数字幅の空白 U+2007 の数）を返す（`point_pads`）。E の数も仮数の小数点で揃え、指数の部分（E-06）は小数部と同じく右に伸びる。小数点の無い数は整数部の右を小数点の位置とする
- **等値線の数値も同じ書き方**。負号は表と同じ「-」にし、U+2212 はやめる。4 桁以上は「,」で区切る（1,200）
- `numerus` は依存を持たない。`charta` と同じく rustruct 固有のものは置かない

## 経緯

E の書き方は 2026-10-26 に Kirchhoff 板の辺の最大値で入れた（`docs/adr/0006`）。そのときは「絶対値が 0.001 未満は E」だけで、E の数は小数点で揃えず列の右に寄せていた。E の混ざる列で小数点がずれ、大きい側の上限も無かったので、範囲を両側に決め、E の数も小数点で揃えることにした。
