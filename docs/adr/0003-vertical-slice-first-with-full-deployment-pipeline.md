# 初回テストは垂直スライスとして、Cloudflare経由アクセスまで一気通貫で検証する

最初のテストは、計算カーネル→UI→DB保存→Dockerコンテナ化→TrueNAS配置→Cloudflare Tunnel経由アクセス、までを一本通す垂直スライスとする。この一環として、区画化3点セット(マウント最小化・専用ブリッジネットワーク・非root実行)・`sqlx migrate`によるマイグレーション管理・`tracing`による最小限のログも、後回しにせず最初から導入する。

理由: SeismicModelのスキーマや計算ロジックを先に磨き込むより、アーキテクチャ全体(特に自分では検証しづらいデプロイ経路)が一度通しで動くことを早期に確認する方が、後工程での手戻りリスクを減らせる。区画化・マイグレーション・ログはいずれも追加コストが小さく、最初から正しい形にしておけば作り直しの手間を避けられる。
