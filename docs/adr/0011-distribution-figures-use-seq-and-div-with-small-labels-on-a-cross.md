# 分布図は seq と div で塗り、等値線は細く、数値は 9px の白抜きを十字に並べる。虹は採らない

板の全面の値を等値線と帯で示す図（分布図。最初の使い手は Kirchhoff 板の曲げ Tool）の見た目を、試作の図を見比べて次のように決めた（2026-10-23、本人が決めた。試作は #37、`prototype/contour` ブランチ）。決め事の一覧は `docs/ui-decisions.md` の「分布図」。

## 決めたこと

- **帯の色**: 正負のない量は `seq`、正負のある量は `div`（どちらも 9 月に作った 12 段）。候補だった虹は採らない
- **段数**: 刻みを 1・2・2.5・5 × 10ⁿ に丸めて帯の境を決める。段数の目安は利用者が選べ、既定はたわみで 10、曲げモーメントで 16。せん断力も正負のある量なので 16 にそろえる
- **等値線**: `ink` 0.25px。0 の線も同じ太さにする
- **線の上の数値**: IBM Plex Mono の 9px、`ink`。縁は地の色（`paper`）2.5px の白抜き。線の向きに沿って傾け、±90° に収める
- **数値の位置**: 板の中心から四辺の中点へ引いた案内線（描かない）と等値線の交点。隣とぶつかれば中心に近い方を残す
- **支持条件の縁**（2026-10-30、#39 で足した）: 固定は `ink` 1px の辺の線と板の外側の 45° の短い斜線（`ink` 0.5px）、単純支持は辺の線だけ、自由は線を引かない。図の下に読み方の注記を置く

## 理由

**虹を採らない**: 虹は隣の段で色相も変わるので、線を1本ずつ追いやすい。しかし、青碧から琥珀へ移る中ほどがくすんだ黄緑になり、図の印象が強くなる。藍の濃淡（`seq`）は明るさだけで段を分けるので色覚の違いに強く、サイトの藍とも馴染む。線を追うのは、線の上の数値で足りる。

**段数を量で変える**: 同じ目安で見比べると、たわみは 10（実際は 7〜8 段）で山の形がよく見えた。曲げモーメントは 16 のほうがよく見えた。`div` は 0 を中心に正負で同じ幅をとるので、固定辺の負が大きい板では正の側に値の無い帯ができ、目安が同じでも塗られる段が少なくなる。図によって見たい細かさが違うので、既定を決めたうえで利用者が選べるようにした。

**細い線**: 0.25px・0.5px・1px と、`line-strong` の 0.5px を並べた。細いほど帯の色が前に出て、図が軽い（Studies の図版の線と同じ「ink の細線」）。0 の線を 1px にして正負の境を目立たせる案は、本人が要らないとした（正負の境は、帯の色相が藍から琥珀へ変わる所でも分かる）。

**数値の位置**: 初めは線ごとに中ほどへ置き、ぶつかれば捨てていた。これでは数値が図のあちこちに散って読みにくかった。そこで、案内線との交点に一列に並べる案を、中心から右・上・右上の角の 3 通りで比べた。1 本の案内線では、交わらない山（四辺固定の Mx の、左右の辺の負の山）が読めない。縦と横の両方に引くことにし、中心から四辺へ引く十字を選んだ。対称な板では同じ値が 2 度ずつ出るが、対称でない支持条件でもどの辺の側も読める。

**9px と白抜きの縁**: 十字に並べると、小数の付く数値（0.5 刻みの「1.5」など）が場所を取ってうるさく見えた。見比べたのは、9px、整数の線にだけ数値を付ける、水平に置く、の 3 案。9px は文字が小さい分、隣とぶつかって抜ける数値も減る。デザインシステムの文字の段（11・13）の外になるので、使うのは等値線の上の数値に限る。縁については、地の色の縁が「うるさく見える原因かもしれない」と本人が言ったので、縁を 1.5px に細くする案と、縁を帯の色にする案（線だけ消え、文字色は帯に応じて `ink` か `paper`）も並べた。見比べたうえで、本人は今の地の色の 2.5px を選んだ。文字を 9px にしたことで、縁の白い島も小さくなっている。

**支持条件の縁**: 構造の図で見慣れた形（固定のハッチ、単純支持の線、自由の無線）を、細線の約束の中で描いた。自由辺を `muted` の破線にする案（線が無いのを描き忘れに見せない）と、縁の外に「固定」「単純支持」「自由」の文字を置く案も並べたが、本人は文字の要らない今の形を選んだ。読み方は図の下の注記で足りる。

## 残っていること

- カラーバーの形（試作では図の右に縦に置き、帯を同じ高さで積み、境に値を書いた）は決めていない
- 案内線と交わらない等値線の値は、カラーバーで読む。片持ち板のように山が隅に寄る図で十分かは、その型の Tool を作るときに見る
- 虹の行と 9px の例外は `docs/design/README.md` に書いた。正本はリポジトリなので、ほかへの反映は要らない（`docs/adr/0012`）
