# スラブたわみ

RC 造二方向スラブ（四辺固定）の必要厚さを、RC 規準のたわみ略算式（解18.2）と表18-1 で求める Tool の言葉。サイト全体の言葉は `GLOSSARY.md`、コンクリート（Fc・γ・γ₁・E）の言葉は `docs/materials/GLOSSARY.md` に従う。

## Language

### スパン・形状

**x方向スパン (Lx)**:
スラブの x 方向の内法スパン。短辺・長辺のどちらであるかは問わない。単位 m。
_Avoid_: 短辺スパン（入力値の意味としては使わない）

**y方向スパン (Ly)**:
スラブの y 方向の内法スパン。短辺・長辺のどちらであるかは問わない。単位 m。
_Avoid_: 長辺スパン（入力値の意味としては使わない）

**短辺スパン (lx)**:
min(Lx, Ly)。たわみの算定とクライテリアの判定の基準になる。

**長辺スパン (ly)**:
max(Lx, Ly)。

**辺長比 (λ)**:
ly / lx。常に 1 以上。

**検討点**:
名称と (Lx, Ly) の組で表す、検討の対象とする1枚のスラブ。1つのスラブたわみ Model は複数の検討点を持てる。
_Avoid_: 検討ケース、部材

### 荷重・材料

**仕上げ荷重 (wf)**:
スラブ自重を除く固定荷重。単位 N/m²。

**積載荷重 (wl)**:
たわみ検討用の積載荷重。単位 N/m²。

**スラブ自重を除く荷重 (wp)**:
仕上げ荷重 + 積載荷重。単位 N/m²。

**全荷重 (w)**:
γ₁·t + wp。たわみの算定に用いる単位面積あたりの荷重。

**共有値**:
検討点のスパンに依らず、条件だけで決まる値（ヤング係数 E・鉄筋コンクリートの単位体積重量 γ₁・wp）。すべての検討点に共通する。

### 判定

**変形増大係数**:
弾性たわみ δe に乗じて、クリープなどによる長期たわみを見込む係数。

**増大後たわみ**:
変形増大係数 × δe。クライテリアと比べるたわみ。
_Avoid_: 長期たわみ（クリープ以外も含むため）

**クライテリア集合**:
同時に満たすべき判定条件の集合。有効な条件が1つも無ければ必要スラブ厚は定まらない。

**クライテリア（変形角）**:
増大後たわみの上限を、短辺スパンとの比で表した条件。増大後たわみ ≤ lx × 変形角。

**クライテリア（たわみ絶対量）**:
増大後たわみの上限を、スパンに依らない値で表した条件。単位 mm。増大後たわみ ≤ たわみ絶対量。

**クライテリア（表18-1 最小厚さ）**:
RC 規準 表18.1（周辺固定）が定めるスラブ厚さの最小値。たわみには効かず、厚さの下限だけを課す。

**たわみに効く条件**:
クライテリアのうち、増大後たわみに上限を課すもの（変形角とたわみ絶対量）。表18-1 は含まない。

**許容たわみ**:
有効なたわみに効く条件が課す上限のうち最小のもの。たわみに効く条件が1つも有効でなければ存在しない。単位 mm。

**必要スラブ厚 (t_req)**:
クライテリア集合の有効な条件をすべて満たす最小のスラブ厚さ。条件ごとの必要厚さの最大値。単位 mm。
_Avoid_: 最小厚さ（表18-1 と紛れる）

**決定条件**:
必要スラブ厚を与えた条件。同値のときはクライテリア集合の並びで先に来る条件とする。

### 図

**等厚曲線**:
スラブ厚 t を固定したとき、クライテリア集合をちょうど満たす (Lx, Ly) の軌跡。y = x に対して対称。

**コンター図**:
x方向スパンを横軸、y方向スパンを縦軸にとり、等厚曲線を重ねて塗り分けた図。
