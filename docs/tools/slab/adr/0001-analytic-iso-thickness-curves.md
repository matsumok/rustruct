# コンターはグリッド計算ではなく等厚曲線の閉形式算定で描く

コンター図は「各グリッド点で必要スラブ厚 t_req を解く」のが素直だが、判定式を t 固定で整理すると lx³·λ⁴/(1+λ⁴) = 32·c·E·t³/(K·w) となり、右辺は t を固定すれば定数になる。λ をパラメータに取れば各等厚曲線 (t = 150, 155, …, 300) は閉形式で正確・滑らかに引けるため、グリッド計算・根探索を全廃してこの方式を採用した。

トレードオフ：グリッドの Z 値が存在しないため、Plotly 標準の「任意点ホバーで t_req 表示」は成立しない。緩和策として、グラフクリック時にその点の t_req を Rust 側で評価して表示する。将来グリッド方式に戻す場合、このホバー要件が復活の動機になるはず — その際もこの閉形式は検算に使えるので残すこと。

2026-10 に slab リポジトリから移した。移した時点の実装では、表18-1 の曲線の下枝（y < x）は二分法、変形角の曲線の下枝も数値解法で引いている。「グリッドを解かずに曲線を直接引く」という判断は変わらないが、すべてが閉形式というわけではない。
