# Kirchhoff 板

長方形の等厚な板に等分布荷重を載せたときの、たわみと応力の板全面の分布を、Kirchhoff 薄板の級数解で求める Tool（Kirchhoff 板の曲げ）の言葉。辺ごとに支持条件を選べる。材料に依らず、ヤング係数とポアソン比を直接与える。サイト全体の言葉は `GLOSSARY.md` に従う。

## Language

### 板の形

**x方向の辺長 (Lx)**:
板の x 方向の長さ。x = 0 の辺と x = Lx の辺の間の距離。長いか短いかは問わない。単位 m。
_Avoid_: スパン、内法（どこからどこまでを測るかは板を使う側が決める）

**y方向の辺長 (Ly)**:
板の y 方向の長さ。y = 0 の辺と y = Ly の辺の間の距離。長いか短いかは問わない。単位 m。
_Avoid_: スパン、内法

**板厚 (t)**:
板の厚さ。全面で一様とする。単位 mm。
_Avoid_: スラブ厚（RC スラブとして使うときの呼び名。この Tool では使わない）

**辺**:
板の 4 つの縁。座標で呼ぶ: x = 0 の辺、x = Lx の辺、y = 0 の辺、y = Ly の辺。画面の上下左右は図の向きで決まる呼び方で、辺の名前としては使わない。
_Avoid_: 上辺・下辺・左辺・右辺、短辺・長辺（辺の名前として）

**板の座標**:
隅を原点とし、x は 0 から Lx、y は 0 から Ly。値を示す点はこの座標で言う。
_Avoid_: 中央を原点とする座標（計算の内部の都合で、表には出さない）

### 支持条件

**支持条件**:
1 つの辺の境界条件。固定・単純支持・自由の 3 つ。記号は F・S・R（自由は R と決めた）。
_Avoid_: 境界条件（解析の一般語として使うのはよい）、支点条件、拘束条件

**固定 (F)**:
辺の上でたわみと、辺に直交する方向の傾きがともに 0 の辺。
_Avoid_: 固定端、完全固定

**単純支持 (S)**:
辺の上でたわみが 0 で、辺に直交する方向の曲げモーメントが 0 の辺。
_Avoid_: ピン、支持（略して使わない）

**自由 (R)**:
支えのない辺。辺に直交する方向の曲げモーメントと、辺の反力がともに 0。
_Avoid_: 自由端、開放

**支持条件の組**:
4 つの辺の支持条件の組。利用者が選んだ辺ごとの値で、Model に保存する。4 文字の記号に並べるときは x = 0 の辺から反時計回り（x = 0 → y = 0 → x = Lx → y = Ly）。この並びは内部の約束で、画面には出さない。
_Avoid_: 境界条件の組合せ

**支持条件の型**:
板を回転・裏返し、x と y を入れ替えて重なる支持条件の組を同じものとしたときの種類。21 種。型は、その型に属する組を並べた 4 文字のうち、F < R < S の辞書順で最小のもので書く（四辺固定は FFFF、四辺単純支持は SSSS）。
_Avoid_: ケース、パターン、境界条件の種類

**不安定な支持条件の組**:
板を支えきれない支持条件の組。四辺自由（RRRR）と、単純支持 1 辺と自由 3 辺（RRRS）の 2 つの型。解は求めない。
_Avoid_: 不静定、エラーの組

### 荷重と材料の値

**等分布荷重 (p)**:
板の全面に一様に載る、単位面積あたりの荷重。下向き正。自重を含めるかは利用者が決め、Tool は導かない。単位 kN/m²。
_Avoid_: 全荷重、面荷重、w

**ヤング係数 (E)**:
板の材料のヤング係数。Tool の入力で、材料から導かない。単位 N/mm²。
_Avoid_: 弾性係数

**ポアソン比 (ν)**:
板の材料のポアソン比。Tool の入力で、既定は 0。
_Avoid_: ポアソン数

**補助入力**:
材料などから E や ν の値を求めて入力欄に書き込む、画面の手助け（例: コンクリートの Fc から E を入れる、鋼材の既定値を入れる）。書き込むのは値だけで、何から求めたかは Model に残さない。
_Avoid_: 材料の選択、プリセット

**曲げ剛性 (D)**:
板の単位幅あたりの曲げ剛性。E·t³ / (12·(1 − ν²))。
_Avoid_: 板剛性、EI

### 結果

**たわみ (w)**:
板の面に直交する変位。下向き正。単位 mm。
_Avoid_: 変位、δ、沈下

**曲げモーメント (Mx, My)**:
単位幅あたりの曲げモーメント。Mx は x 方向に応力 σx を生じさせるもの（x に直交する断面に働く）、My は y 方向について同じ。下側の繊維が引張になる向きを正。単位 kN·m/m。
_Avoid_: 応力（総称として使わない）、モーメント（略して使わない）

**せん断力 (Qx, Qy)**:
単位幅あたりの面外せん断力。Qx は x に直交する断面に、Qy は y に直交する断面に働く。正の向きは板理論の通常の向きに従う。単位 kN/m。
_Avoid_: 剪断力

**辺の反力 (Vx, Vy)**:
固定または単純支持の辺が板を支える、辺に沿った単位長さあたりの力。Vx は x = 0 と x = Lx の辺の、Vy は y = 0 と y = Ly の辺の反力。支える向き（上向き）を正。単位 kN/m。せん断力とねじりモーメントの変化から求める。
_Avoid_: 支点反力、等価せん断力（求め方の名前で、結果の名前としては使わない）

**ねじりモーメント (Mxy)**:
単位幅あたりのねじりモーメント。計算の内部では求めるが、結果として示さない。

**隅反力**:
単純支持の辺どうしの隅（と、単純支持の辺と自由辺の隅）に集中して生じる、支持が板を押さえる力。隅ごとに 1 つの値として示す。板を下に押さえる向きを正。固定辺を含む隅（固定辺どうし、固定辺と自由辺など）と、自由辺どうしの隅では 0。辺の反力の合計から隅反力の合計を引くと、荷重の合計に等しい。単位 kN。

**辺の最大値**:
1 つの辺に沿って評価点を並べたときの、せん断力（その辺に直交する断面のもの）と辺の反力それぞれの絶対値の最大と、その位置（辺の始点からの距離）。結果の表に辺ごとに示す。
_Avoid_: 端部せん断力、最大反力（位置を省いた呼び方）

**分布図**:
板の全面で、たわみ・曲げモーメント・せん断力のどれか 1 つの値を等値線と塗り分けで示した図。
_Avoid_: コンター図（必要スラブ厚さ Tool の等厚曲線の図を指す）

**評価点**:
結果の値を求める板の上の点。分布図は評価点を等間隔に並べたグリッドの値から描く。

### 級数解

**級数解**:
たわみを三角関数と双曲線関数の項の和で表す解き方。支持条件の型ごとに項の形と、境界条件から決める未知の係数の組が変わる。
_Avoid_: 厳密解、理論解

**項数**:
級数を打ち切る項の数。Tool の定数で、利用者は選ばない。
_Avoid_: 次数、分割数
