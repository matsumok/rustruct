# 級数の項数は計算の定数とし、収束のテストで決める

級数の項数はKirchhoff 板の計算に置く定数とし、利用者の入力にも Model にも持たない（2026-10-22、本人が決めた）。値は収束のテストで決める。

曲げモーメントは少ない項数で落ち着くが、せん断力と辺の反力はたわみの 3 階の導関数から求めるので収束が遅く、固定辺と自由辺の隅の近くでは特に遅い。決め方は次のとおり。板の内部のたわみ・曲げモーメント・せん断力は、項数 N と 2N の差が許容誤差に収まること。辺の反力は、辺に沿う向きの展開（ADR-0002）で、N = 20 以上で同じく収まること。隅反力（隅の w_xy から求める）も N と 2N の差が収まること。項数はこの両方を満たす最小の値とする。量ごとに項数を変えると、同じ点のモーメントとせん断力が別の解から出ることになるので、項数は一つにする。

## 値: 80（2026-10-23、四辺固定で決めた）

許容誤差は「その量の絶対値の最大の 1e-3」とし、評価点は隅から辺長の 5 % 以内を除く。縦横比 1・2・4 の板で、21 × 21 のグリッド（辺の上の点を含む）の w・Mx・My・Qx・Qy と、各辺を 100 等分した点の辺の反力・せん断力・曲げモーメントを見た（`crates/rustruct-calc/tests/kirchhoff_plate.rs` の収束テスト）。

- 項数 40 では縦横比 4 のせん断力の差が 3.5e-3、60 では 1.3e-3 で届かない。80 で全量が 1e-3 を下回る（たわみは 1e-10、曲げモーメントは 1e-5 の桁、せん断力と辺の反力が 1e-3 の桁）
- 辺の反力の収束は、隅を除けばせん断力と同じ速さ（80 と 160 の差が最大の 4e-4 程度）。辺を横切る向きの同次解（x の辺なら y = ±Ly/2 の辺のモーメントの項）は、辺の上では隅からの距離に対して指数的に減る項の和になり、辺に沿う展開の収束を落とさない
- 隅から辺長の 5 % 以内は、項数を倍にしても級数が振れる（辺の反力で最大の 1〜2 %、せん断力で 1 % 弱）。固定辺どうしの隅では厳密な値は 0 で、級数はその近くで符号を変えながら 0 に向かう。これは級数の性質で、項数では消えない。隅の近くの値の見せ方は別に決める（Issue #41）
- 四辺単純支持（`crates/rustruct-calc/tests/kirchhoff_plate_simply_supported.rs`）でも 80 で足りる。グリッドは隅の近くも 1e-3 に収まり、外れるのは隅の点そのもののせん断力だけ（厳密な値は 0 で、級数は 1/N でしか近づかず、80 項で最大の 4e-3 程度）。辺の反力は隅で 0 から急に立ち上がり、隅から辺長の 5 % 以内では級数が振れる（縦横比 4 の長辺で最大の 1.4e-3）ので、四辺固定と同じくそこを除いて見る。辺の中央と 1/4 点の反力の誤差は、項数を倍にするごとに 1/4 になる
- 計算の時間は、連立が小さい（2N = 160 元）ので評価が主で、51 × 51 のグリッドと辺 4 本で項数 40 の 54 ms に対し 80 で 79 ms（ネイティブ）。項数を倍にしても大きく増えない

項数を入力にして利用者に選ばせる案は、選ぶ根拠を利用者に求めることになり、Model に入ると古い Model の結果の再現にも関わるので退けた。項数を変えるときは、この ADR と収束のテストを同じ変更で直す。
