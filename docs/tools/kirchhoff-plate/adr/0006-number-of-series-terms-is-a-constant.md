# 級数の項数は計算の定数とし、収束のテストで決める

級数の項数はKirchhoff 板の計算に置く定数とし、利用者の入力にも Model にも持たない（2026-10-22、本人が決めた）。値は収束のテストで決める（まだ決めていない）。

曲げモーメントは少ない項数で落ち着くが、せん断力と辺の反力はたわみの 3 階の導関数から求めるので収束が遅く、固定辺と自由辺が会う角の近くでは特に遅い。決め方は次のとおり。板の内部のたわみ・曲げモーメント・せん断力は、項数 N と 2N の差が許容誤差に収まること。辺の反力は、辺に沿う向きの展開（ADR-0002）で、N = 20 以上で同じく収まること。隅反力（角の w_xy から求める）も N と 2N の差が収まること。項数はこの両方を満たす最小の値とする。量ごとに項数を変えると、同じ点のモーメントとせん断力が別の解から出ることになるので、項数は一つにする。

項数を入力にして利用者に選ばせる案は、選ぶ根拠を利用者に求めることになり、Model に入ると古い Model の結果の再現にも関わるので退けた。項数を変えるときは、この ADR と収束のテストを同じ変更で直す。
