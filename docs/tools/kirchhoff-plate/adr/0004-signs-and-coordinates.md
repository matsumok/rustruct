# たわみは下向き、曲げモーメントは下側引張、反力は支える向きを正とし、座標は隅を原点にする

Kirchhoff 板の結果の符号と座標を次のように決める（2026-10-22）。

- たわみ: 下向き（荷重の向き）を正
- 曲げモーメント Mx・My: 板の下側の繊維が引張になる向きを正。四辺固定の板なら中央で正、固定辺で負になる
- せん断力 Qx・Qy: 板理論の通常の向き。x の大きい側の断面で下向きに働くものを正
- 辺の反力 Vx・Vy: 板を支える向き（上向き）を正。荷重を受けている辺では正になる
- 隅反力: 支持から板へ働く向き、つまり板を下に押さえる向きを正。辺の反力と同じく「支持が板に及ぼす力」として読むが、通常の向きが逆なので、正の値どうしで比べられるようにした。釣り合いは「辺の反力の合計 − 隅反力の合計 = 荷重の合計」
- 等分布荷重: 下向きを正
- 座標: 隅を原点とし、x は 0 から Lx、y は 0 から Ly

画面や表で値を示すときは、この座標とこの符号で言う。計算の内部では、対称性をそのまま使えるように板の中央を原点にし、隅原点との変換は計算の入口と出口の一箇所だけで行う。

曲げモーメントの符号は、上側引張を正とする流儀もある。下側引張を正にすると、荷重で下に凸に曲がるところが正になり、板のどちらの面が引張かが符号からそのまま読める（RC スラブとして使うなら、正が下端筋、負が上端筋に対応する）。反力は、板理論の流儀ではせん断力と同じ向きの符号で負になることがあるが、支える力として読む人が多いので支える向きを正にした。

座標の原点を板の中央に置く案は、級数の式とは揃うが、画面の軸（0 から Lx）と合わず、評価点を言うたびに換算が要るので退けた。
