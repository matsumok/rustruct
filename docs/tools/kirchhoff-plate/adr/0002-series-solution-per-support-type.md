# 板は Kirchhoff 薄板の級数解で、支持条件の型ごとに解く

Kirchhoff 板の曲げは、板を Kirchhoff 薄板として扱い、たわみを級数で表して解く（2026-10-22、本人が決めた）。級数の項の形（三角関数と双曲線関数の組み合わせ）と、境界条件から決める未知の係数の組は支持条件の型ごとに違うので、型ごとに別の解き方を `rustruct-calc` に書く。向かい合う 2 辺が単純支持なら Lévy 型の単一級数で閉じる。四辺単純支持もこれに含め、Lévy 型の単一級数（両方向）で解く。Navier の二重級数は実装には使わず、テストで独立な解として照合するのに使う（辺の反力の収束が遅いため、次の段落）。それ以外は辺の上の未知の曲げモーメントやたわみを級数で置いて、境界条件から連立一次方程式を立てる。

21 種の支持条件の型（ADR-0003）のうち、不安定な 2 種を除く 19 種が対象。先に作るのは次の 18 種で、四辺固定（FFFF）→ 四辺単純支持（SSSS）→ 三辺固定一辺自由（FFFR）→ 残り、の順に足す。

FFFF FFFR FFFS FFRR FFRS FFSS FRFS FRRR FRRS FRSR FRSS FSFS FSRS FSSS RRSS RSRS RSSS SSSS

向かい合う 2 辺が固定で残る 2 辺が自由の型（FRFR）だけは後に回す。まだ解き方の無い型は、計算で「未対応」と返す。

片持ちの板（FRRR）と、固定と単純支持が向かい合い残る 2 辺が自由の板（FRSR）は、等分布荷重で ν = 0 なら梁の解と一致する。ν ≠ 0 では自由辺で y 方向の曲げモーメントが 0 になる条件に ν が入り、梁の解からずれるので、ほかの型と同じく板として解く。梁の解は、ν = 0 のときのテストの期待値として使う。

型ごとの解き方が返すのは、無次元のたわみとその 1〜3 階の導関数だけにする。曲げモーメント・せん断力・辺の反力は、導関数から一箇所で求める。こうすると、型を足すたびにモーメントや反力の式を書き直さずに済み、符号やポアソン比の入れ方が型ごとに揃わない、ということが構造的に起こらない。双曲線関数は、大きな引数で値が溢れないよう、比の形にした関数だけを通して呼ぶ。

辺の反力は、その辺に沿う向きに展開した級数で求める。x = 0 と x = Lx の辺なら y 方向の三角関数の級数で、y の辺なら x 方向の級数で表した形を使う。四辺単純支持の検算では、板の内部のたわみ・曲げモーメント・せん断力はどちらの向きの展開でも、Navier の二重級数でも同じ値に収束した。ところが辺の上の反力は、辺に沿う展開なら誤差が項数の 2 乗に反比例して減ったのに対し、辺を横切る展開と二重級数では 1 乗に反比例してしか減らなかった。固定辺のある型では、辺の曲げモーメントの級数そのものの収束が遅く、辺に沿う展開でも同じ速さになるとは限らない。反力にはどの型でも辺に沿う展開を使い、収束の速さは一般には言わず、型ごとに ADR-0006 の決め方で確かめる。このため各型は荷重の項を両方向の Lévy 型の級数で持ち、辺の評価は内部の点の評価とは別の入口にして、反力が辺に沿う展開からしか求まらないようにする。

ほかの解き方も比べた。

- 有限要素法・差分法は、どの支持条件にも同じ道具で対応できるが、メッシュの粗さで結果が変わり、要素と収束の判断を利用者か Tool が持つことになる。級数解は境界条件を厳密に満たし、項数を増やすと決まった値に収束するので、ほかの解き方を検算する基準にもなる
- 21 種すべてを一つの汎用の仕組み（各辺に未知の関数を置き、方程式を機械的に組み立てる）で解く案は、コードは最も短いが、型ごとの式が読めなくなり、本人が式をレビューできない（CODING_STANDARDS「計算は本人がレビューする」）。いくつかの型を書いて共通の形が見えたら、部品を寄せる
- 設計規準の略算式や係数表は、特定の支持条件の代表点の値しか持たず、板全面の分布と辺ごとの支持条件の要件に足りない。材料ごとの規準に寄ることにもなる
