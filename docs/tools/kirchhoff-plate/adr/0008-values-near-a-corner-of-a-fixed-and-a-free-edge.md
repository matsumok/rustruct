# 固定辺と自由辺の隅の近くは、隅から辺長の 5 % を除いて見せる

固定辺と自由辺の隅では、せん断力と辺の反力が発散する。隅の一点の値は計算を細かくするほど大きくなり、隅のすぐ近くの値も定まらない。曲げモーメントとたわみは隅まで定まる。隅の近くの値を次のように見せる（2026-10-23、本人が決めた）。

- 分布図の色の幅は、隅から辺長の 5 % 以内の点を除いて決める。隅の近くの値は色の端で振り切れる。評価点は動かさない
- 辺の最大値は、せん断力と辺の反力では両端から辺長の 5 % を除いた範囲で取る。曲げモーメントは隅まで含める
- 5 % は、計算の収束を確かめるときに除く幅（ADR-0006）と同じにする。収束を確かめていない範囲の値で、色の幅と最大値を決めないため

## 結果の注記

自由辺のある型では、結果に次の注記を付ける。3 つ目は ν ≠ 0 のときだけ。

- 固定辺と自由辺の隅では、せん断力と辺の反力が発散する
- 辺のせん断力と反力の最大値は、隅から辺長の 5 % を除いた範囲で取る
- ν ≠ 0 では、自由辺のある場合、せん断力と辺の反力が収束しない

ν ≠ 0 の扱いは ADR-0005。
