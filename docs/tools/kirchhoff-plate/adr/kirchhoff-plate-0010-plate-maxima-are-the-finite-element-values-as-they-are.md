# 板全体の最大値は、格子から選んで要素の中まで詰め、有限要素の値をそのまま返す

板全体の最大値（たわみ、Mx・My の下側引張と上側引張、Qx・Qy）とその位置を、計算核の `Solution::maxima` が返す（2026-11-25、#142。値の規則は本人が決め、取り方は Issue が任せたもの）。位置は隅 x = 0・y = 0 からの座標（ADR kirchhoff-plate-0004）。

## 値の規則

- w は最大たわみ（`Solution::deflection_maximum`、ADR kirchhoff-plate-0009）の値と位置
- Mx・My は向きごとに取る。下側引張は正の最大、上側引張は負で絶対値の最大
- Qx・Qy は絶対値が最大の点の、符号つきの値。符号は `PointResponse` と同じ板理論の向き（ADR kirchhoff-plate-0004）
- 値は有限要素の値そのもの。0 に丸めず、辺の上の値も直さない。四辺単純支持の上側引張の Mx・My は、有限要素の小さな値（2000 × 2000、ν = 0.2 で −9.1E-05 N·mm/mm、x = Lx の辺の上）とその位置になる。画面では指数で出る（ADR site-0013）
- 値 0・位置無しは、板のどこにもその符号の値が無い（ちょうど 0 か逆の符号だけの）ときだけ。荷重 0 の板など
- せん断力は、自由辺のある組では隅から辺長の 5 % 以内の点（`Solution::near_corner`）を除いて取る（ADR kirchhoff-plate-0008 の辺の最大値の規則を板全体に広げたもの）。曲げモーメントは隅まで含める
- 同じ大きさの最大が、板を辺に平行な中心線で折り返した点にもあるときは、原点に近い側（y、次に x の小さいほう）を返す。差がその値の 1e-9 以下なら同じ大きさとみなす（ADR kirchhoff-plate-0009 と同じ規則と幅）。四辺固定の上側引張の Mx は x = 0 の辺の中央、My は y = 0 の辺の中央

縦横比 1.5 の四辺固定（2000 × 3000、ν = 0.2）の My の下側引張は、中央でなく、中央をはさむ x = 1000 mm、y ≈ 1239 mm と 1761 mm の 2 点で最大になる（677.9 N·mm/mm。中央は 675.8 N·mm/mm）。級数解でも同じで、原点に近い y ≈ 1239 mm を返す。四辺単純支持の長い辺の向きの曲げモーメントも、縦横比と ν によって中央の外で最大になる。

## 取り方

- 板を等分した格子の点で値を見る。短い辺を 40 等分し、長い辺は辺長に合わせて増やす（偶数、400 まで）。格子は辺の上の点を含むので、辺の上の最大（固定辺の上側引張、辺のせん断力）を取りこぼさない
- 量ごとに、格子の点から最大の点を選び（同じ値なら y、次に x の小さい点）、その点に接する格子の目の中で `Solution::at` の値を詰める。詰め方は最大たわみと同じ（ADR kirchhoff-plate-0009。±h に 9 × 9 点、h を 1/4 にして 12 回。目の外は目の端に寄せるので、辺の上の点は辺の上に留まる）
- 詰めた値が 0 以下（せん断力は絶対値が 0）なら、値 0・位置無し

最大は選んだ格子の点に接する目の中にあるとみなす。

節点から選ぶ案は退けた。節点は余弦の間隔で板の中ほどが粗く、参照解（級数解）には節点が無い。等分の格子は、有限要素と参照解が同じ `Solution::at` の上で同じ手順を通る。詰めるので、分割数を変えても位置が節点の間隔で跳ばない。

## 決めたときに外したもの

Issue を書いたときは、その曲げの |M| の板全体の最大の 1e-9 倍以下の値を 0 とみなし、値 0・位置無しで返す規則があった。四辺単純支持の上側引張を 0 にするためのもの。有限要素は単純支持の辺の上の曲げモーメントをちょうど 0 にせず（板全体の最大の 1E-08〜6E-08）、この幅では 0 にならなかった。境界条件で 0 になる曲げモーメントを辺の上でちょうど 0 にする案と、幅を広げる案もあったが、本人が有限要素の値をそのまま出すと決め、1e-9 の規則も外した（2026-11-25、#142 のコメント）。

## 参照解

参照解の級数（ADR kirchhoff-plate-0002）も、同じ `Solution::maxima` が同じ格子と手順で取る。照合テストのためだけにある。

## テスト

計算核（`tests/kirchhoff_plate.rs`）: 四辺固定（縦横比 1、1.5）で、下側引張の Mx・My が中央の値と位置（縦横比 1.5 の My は中央をはさむ 2 点のうち原点に近い側で、中央の値より大きい）。上側引張の Mx・My と Qx・Qy が x = 0・y = 0 の辺の `edge_maximum` の値と一致し、位置がその辺の中央。四辺単純支持の上側引張は小さな負の値と位置で、大きさが M の許容（下側引張の最大の 0.5 %）より小さい。三辺固定一辺自由で、Qx・Qy の位置が隅から辺長の 5 % 以内に無い。対称でない組を裏返すと位置が裏返る。19 型で、グリッドの点と辺の評価点のどれも最大値を超えない。荷重 0 の板では値 0・位置無し。

照合（`tests/kirchhoff_plate_series_reference.rs`）: 四辺固定・四辺単純支持（縦横比 1、1.5）で、Mx・My の向きごとの最大値が参照解の最大と M の許容（ADR kirchhoff-plate-0002）で、位置が辺長の 1e-3 で一致する。四辺単純支持の上側引張は位置を比べない（どちらの解も 0 に近い小さな値で、位置に意味が無い）。
