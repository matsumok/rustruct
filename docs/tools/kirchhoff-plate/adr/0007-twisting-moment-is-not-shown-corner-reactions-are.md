# ねじりモーメントは示さないが、隅反力は隅ごとの値として示す

Kirchhoff 板の結果は、板全面のたわみ・曲げモーメント Mx と My・せん断力 Qx と Qy、辺の反力 Vx と Vy、隅ごとの隅反力とする。ねじりモーメント Mxy の分布は示さない（2026-10-22、本人が決めた）。一度は隅反力も示さないと決めたが、改めた。

隅反力は、単純支持の辺どうしの隅と、単純支持の辺と自由辺の隅に集中して生じる、支持が板を押さえる力。隅のねじりモーメントの 2 倍で、計算の内部で持つたわみの導関数 w_xy からそのまま求まる。固定辺を含む隅では辺に沿ってねじれが起きないので 0、自由辺どうしの隅では支えが無いので 0。

示すことにしたのは、小さくないからだ。四辺単純支持の検算では、辺の反力の合計は荷重の合計の 1.13〜1.37 倍（正方形で約 1.26 倍）になり、差の分を隅反力が下向きに押さえて釣り合う。隅反力を示さないと、辺の反力の合計が荷重と合わず、読む人が戸惑う。値は隅 4 点のスカラーで、分布図も評価点も要らない。画面では「辺の反力の合計 − 隅反力の合計 = 荷重の合計」が見える形にする（符号は ADR-0004。隅反力は押さえる向きを正とするので、引き算になる）。

ねじりモーメントの分布は、隅の補強を考えるとき（RC スラブなら隅の配筋）に要るが、今回の目的（板全面の曲げとせん断の分布を見る）には入らない。示す量を増やすのは、使い方がはっきりしてからにする。
