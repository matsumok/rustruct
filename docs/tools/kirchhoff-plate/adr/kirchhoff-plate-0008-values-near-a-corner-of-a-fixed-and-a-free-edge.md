# 固定辺と自由辺の隅の近くは、隅から辺長の 5 % を除いて見せる

固定辺と自由辺の隅では、せん断力と辺の反力が発散する。隅の一点の値は計算を細かくするほど大きくなり、隅のすぐ近くの値も定まらない。曲げモーメントとたわみは隅まで定まる。隅の近くの値を次のように見せる（2026-10-23、本人が決めた）。

- 分布図の色の幅は、隅から辺長の 5 % 以内の点を除いて決める。隅の近くの値は色の端で振り切れる。評価点は動かさない
- 辺の最大値は、せん断力と辺の反力では両端から辺長の 5 % を除いた範囲で取る。曲げモーメントは隅まで含める
- 5 % は、計算の精度を参照解と照合するときに除く幅（ADR kirchhoff-plate-0002、ADR kirchhoff-plate-0006）と同じにする。照合していない範囲の値で、色の幅と最大値を決めないため

隅から辺長の 5 % 以内の点は、照合と同じく、x と y のどちらも辺長の 5 % より端に寄った点とする。除くのは自由辺のある組だけで、その組では 4 つの隅と各辺の両端で除く（下の注記が言うとおりにするため。ページを作るときに決めた、#42）。自由辺の無い組は隅まで含めて見せる。

規則は計算核の `Solution` が持ち、画面と照合はそれを呼ぶ（2026-11-03、#82）。5 % は計算核の定数 `CORNER_MARGIN` で、辺の最大値は `Solution::edge_maximum` が自由辺のある組でこの規則どおりに取り、隅から辺長の 5 % 以内の点かは `Solution::near_corner` が答える。自由辺のある組かは `Supports::has_free_edge` で、分布図の色の幅でこれを見て除くかを決めるのは呼び手。ちょうど辺長の 5 % にある評価点は、丸めで外れないよう少しの幅を見て除かない。それまでは同じ規則を画面とテストがそれぞれ書いていた。

## 結果の注記

自由辺のある型では、結果に次の注記を付ける。

- 固定辺と自由辺の隅では、せん断力と辺の反力が発散する
- 辺のせん断力と反力の最大値は、隅から辺長の 5 % を除いた範囲で取る

分布図には、支持条件の読み方に続けて「色の幅は、隅から辺長の 5 % 以内の点を除いて決める」を付ける（隅の近くが色の端で振り切れるわけを言うため。#42）。

決めたときは 3 つ目に「ν ≠ 0 では、自由辺のある場合、せん断力と辺の反力が収束しない」があった。級数解の振れで、有限要素に一本化して（ADR kirchhoff-plate-0002、同じ 2026-10-23）無くなったので外した。ν ≠ 0 の扱いは ADR kirchhoff-plate-0005。
