# 最大たわみは要素の中まで見て取る

板全体の |w| の最大とその位置（最大たわみ）は、節点だけでなく要素の中まで見て取る（2026-11-03、#76。Issue が「決めて ADR に書く」としたもの）。

取り方は次のとおり。計算核の `Solution::deflection_maximum` が持つ。

- 有限要素の節点の w から、|w| が最大の節点を選ぶ
- その節点に接する要素（最大 4 つ）の範囲で、形状関数の w（要素の中の双 3 次式。要素の間で連続）を詰める。今の点から ±h の範囲に 9 × 9 点を置き（範囲の外は範囲の端に寄せる）、|w| が最大の点に移って h を 1/4 にする、を 12 回。最初の h は接する要素の幅で、最後の点の間隔は要素の幅の 1e-8 の桁
- 同じ大きさの最大が、板を辺に平行な中心線で折り返した点にもあるとき（対辺がともに自由な板など）は、原点に近い側（y、次に x の小さいほう）を返す。|w| の差が |w| の 1e-9 以下なら同じ大きさとみなす。節点を探す順と写し方（ADR kirchhoff-plate-0003）で、どちらが出るかが組ごとに変わらないようにするため

節点だけで見る案は退けた。節点は余弦の間隔で、板の中ほどの要素の幅は辺長の約 4 % ある。対称でない組では最大が節点の間に来て、節点だけで見ると位置がその幅に丸まる（2000 × 3000、ν = 0.2 の、x = 0 と y = 0 が固定・残りが単純支持の組で、最大は x = 1143 mm、y = 1656 mm。x の最寄りの節点から 13 mm）。値の差は小さいが、表に出す位置が、分割数を変えると跳ぶ値になる。要素の中の w は有限要素の解そのものなので、詰めても新しい近似は入らない。

最大は選んだ節点に接する要素の中にあるとみなす。w は要素の幅に比べてゆっくり変わり、選んだ節点より大きい山が、ほかの節点を越えずに離れた要素の中だけに立つことはない。

## 画面

結果の「最大たわみ」の表に、w（mm）・x（m）・y（m）を 1 行で出す。「板の中央」の表のすぐ下、「辺の最大値」の前に置き、解けない組では「—」（`docs/ui-decisions.md`「列の単位と表」）。たわみの符号は板の中央の表と同じく下向きが正で、位置は隅 x = 0・y = 0 からの座標（ADR kirchhoff-plate-0004）。

## 参照解

参照解の級数（ADR kirchhoff-plate-0002）には節点が無いので、x の辺長を 40 等分する間隔の格子から同じ手順で詰める。照合テストのためだけにある。

## テスト

計算核（`tests/kirchhoff_plate.rs`）: 四辺固定・四辺単純支持で最大が中央と一致する（縦横比 1、1.5、2.5）。三辺固定一辺自由で、自由辺をどの辺に置いても最大がその辺の中央に来て、辺に直交する座標はちょうど辺の上。対称でない組を裏返すと位置が裏返る。対辺が自由な組で原点に近い側を返す。`tests/kirchhoff_plate_series_reference.rs` で、四辺固定・四辺単純支持の値が参照解の最大と w の許容（ADR kirchhoff-plate-0002）で一致する。画面（`crates/rustruct-web/tests/kirchhoff_plate.rs`）は表の並びと値の書き方、解けない組の「—」。
