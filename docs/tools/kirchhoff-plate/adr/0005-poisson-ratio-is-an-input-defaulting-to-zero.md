# ポアソン比は Kirchhoff 板の入力で既定 0 とし、常にその値を入れて解く

ポアソン比 ν は Kirchhoff 板 Model の入力にし、既定を 0 とする（2026-10-22、本人が決めた）。

ν は材料の値だが、この Tool は材料に依らない（ADR-0001）ので、E と同じく直接入力にし、材料から求めるのは補助入力に任せる。既定を 0 にしたのは、材料を決めずに開いたときに特定の材料の値を仮定しないためと、梁の解と比べるとき（ν = 0 なら一方向に曲がる板は梁と一致する）にそのまま使えるため。RC スラブの解析では、ひび割れの影響をならして ν = 0 と置く慣例もある。

計算は、入力された ν を曲げ剛性と境界条件に入れて解く。ν = 0 の結果から他の ν の値へ換算する方法は、境界条件に ν が入らない支持条件の型（自由辺の無い型）でしか成り立たない。自由辺の曲げモーメントと反力が 0 という条件には ν が入るので、換算と解き直しを型によって使い分けることになる。自由辺の無い型でも、辺の反力は曲げモーメントと同じ形の換算に乗らない。反力は ν = 0 の反力に νD·∂³w/∂x∂y² のような導関数の項を足した形になり、ν = 0 の反力どうしの組み合わせでは表せない。式を一本に保つため、換算は使わない。換算が成り立つことは、自由辺の無い型のテストで確かめる。

ν の入力の範囲は 0 ≤ ν < 0.5 とする。範囲は型（`PoissonRatio`）の生成で守り、`Concrete::new` と同じく範囲の外は作れずに理由を返す。0.5 では曲げ剛性の式の分母 1 − ν² は 0 にならないが、等方弾性体の体積弾性率が無限大になり、材料として意味をなさない。負のポアソン比を持つ材料もあるが、構造に使う材料には当たらないので扱わない。
