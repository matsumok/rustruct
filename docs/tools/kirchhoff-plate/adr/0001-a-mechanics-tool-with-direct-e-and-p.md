# Kirchhoff 板の曲げは Mechanics の Tool とし、1 つの Model は 1 枚の板を持ち、E と p は直接入力する

長方形の等厚な板のたわみと応力の分布を求める機能を、Mechanics の Tool「Kirchhoff 板の曲げ」（`/tools/kirchhoff-plate/`）として置く（2026-10-22、本人が決めた）。板の解析は材料に依らないので、RC のような材料の分野には置かない（分野の判断はサイトの ADR-0010）。RC スラブの必要スラブ厚さとも、将来のスラブ設計とも別の Tool で、スラブ設計はこの Tool の計算核と言葉を使う側になる。

1 つの Kirchhoff 板 Model は 1 枚の板を持ち、保存するのは次の値だけ。

- x方向の辺長 Lx・y方向の辺長 Ly（入力は m）
- 板厚 t（入力は mm）
- ヤング係数 E（入力は N/mm²）
- ポアソン比 ν（既定 0、ADR-0005）
- 等分布荷重 p（入力は kN/m²）
- 4 辺の支持条件の組

内部の値は ADR-0004 どおり N・mm の系に揃える。曲げ剛性・支持条件の型・級数の係数・結果は保存しない（導出できる値は保存しない）。保存を実装する一本の前に、ADR-0004 が予告した保存形式（内部の系と保存 JSON の単位）の見直しを行う。

E は直接入力にする。一度は「コンクリートの Fc から材料の式で E を導き、Model には Fc を持つ」と決めたが、それでは Tool が RC に縛られる。「コンクリートの Fc から E を入れる」「鋼材の既定値を入れる」といった手助けは、画面の補助入力として後で足す。補助入力は求めた値を入力欄に書き込むだけで、何から求めたか（Fc や材料の種類）は Model に残さない。「導出できる値は保存しない」と逆向きに見えるが、この Tool にとって E は入力そのもので、材料は Tool の外にある。Fc を保存して E を導く形にすると、材料ごとに Model の形が分かれ、材料に依らない Tool でなくなる。

等分布荷重も直接入力にする。自重を板厚から導くと、厚さを変えたときに荷重が追従する利点はあるが、単位体積重量という材料の値が要る。何を荷重に含めるかは利用者に任せる。

1 つの Model に複数の板を並べる案は、板ごとに条件がすべて変わり、共有する値が無いので退けた。並べて比べたくなったら、Model を複数持つことで足りる。
