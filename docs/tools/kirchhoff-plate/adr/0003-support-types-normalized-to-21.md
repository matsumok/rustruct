# 支持条件の組は対称性で 21 種の型にまとめ、写し方を一つの値に閉じ込める

支持条件の組と、それを回転・裏返し・x と y の入れ替えでまとめた 21 種の支持条件の型、型を書く記号の約束は `docs/tools/kirchhoff-plate/GLOSSARY.md` が定める。この ADR は、計算がそれをどう使うかを決める（2026-10-22）。4 つの辺の選び方は 81 通りあるが、計算は、利用者が選んだ組をまず代表の型と「代表から元の組への写し方」に分け、代表の型だけを解き、結果を写し方で元の座標に戻す。

写し方は、座標の写し方と、結果の量の写し方の両方を 1 つの値として持つ。x と y を入れ替えると Mx と My、Qx と Qy、Vx と Vy が入れ替わり、x の向きを裏返すと Qx の符号が変わる。角も写し方で入れ替わる（隅反力は向きを持たないので、値はそのまま角だけが移る）。この符号の扱いを型ごとの解き方に散らさず、一箇所に閉じ込める。型ごとの解き方は代表の向きだけを知る。

代表の向きは、型を書く 4 文字（GLOSSARY の約束どおり、x = 0 の辺から反時計回りに並べて辞書順で最小のもの）がそのまま x = 0、y = 0、x = Lx、y = Ly の辺の支持条件になる向きとする。型ごとの解き方はこの向きの板だけを解く。

型は 21 の列挙子を持つ列挙型にし、解き方への振り分けは網羅的な `match` で書く。21 種のどれにも「解き方がある」「まだ無い」「不安定」のどれかを決めたことを、コンパイラが確かめる。

不安定な支持条件の組（GLOSSARY の RRRR と RRRS）は、計算が拒む。支持条件の組そのものは作れる。画面で辺を 1 つずつ選ぶ途中で不安定な組を通るので、作れなくすると入力の途中を表せない。隣り合う 2 辺が単純支持で残りが自由の組（RRSS）は、支持線が一直線に並ばないので安定。

Model には利用者が選んだ 4 辺の支持条件をそのまま保存し、型と写し方は保存しない（導出できる値は保存しない）。

正規化せず 81 通りすべてを `match` で振り分ける案も比べた。網羅は同じく機械で確かめられるが、同じ解き方への別名が並び、写し方の符号をあちこちで書くことになる。x と y の入れ替えを使わず、回転と裏返しだけでまとめる案（36 種）は、Lx と Ly の入れ替えが写し方の中で閉じるので、使わない理由が無い。
