# コンクリートの単位体積重量は Fc の区分の表から導き、Fc 18〜100 の外はワーニングで計算する

コンクリートは設計基準強度 Fc と種類だけで特定する。気乾単位体積重量 γ は下の表を Fc の区分で引き、鉄筋コンクリートの単位体積重量 γ₁ は γ + 1 kN/m³ で導く。ヤング係数 E は Fc と γ から RC 規準の式 E = 3.35×10⁴ × (γ/24)² × (Fc/60)^(1/3) で求める。Fc が 18 未満か 100 超でもコンクリートは作れて計算もでき、範囲を外れていることをワーニングとして返す（本人の判断、2026-10-14）。18 未満は表の最初の区分に入る。100 超は表に区分が無いので、最後の区分（γ = 25.0）を延ばして使う。正の有限値でない Fc は E の式が意味をなさないので作れない。一時は範囲外を作れなくしたが、小さな Fc でも計算はさせたいので、止めずに知らせる形にした。

| Fc (N/mm²) | γ (kN/m³) | γ₁ (kN/m³) |
|---|---|---|
| 18 ≦ Fc ≦ 36 | 23.0 | 24.0 |
| 36 < Fc ≦ 48 | 23.5 | 24.5 |
| 48 < Fc ≦ 60 | 24.0 | 25.0 |
| 60 < Fc ≦ 80 | 24.5 | 25.5 |
| 80 < Fc ≦ 100 | 25.0 | 26.0 |

値は実務の慣例として本人が示したもので（2026-10-14）、出典は明記しない。示された表は γ を「無筋コンクリートの単位容積重量」、γ₁ を「鉄筋コンクリートの単位容積重量」と呼ぶが、言葉は RC 規準の呼び方に揃える（`docs/materials/GLOSSARY.md`）。γ₁ の列はどの区分でも γ + 1 なので持たず、表と一致することをテストで確かめる。

移植元の slab は γ = 23、γ₁ = 24 を Fc に依らない定数としていた。Fc 36 以下ではこれと一致するが、それを超えると E と自重が変わり、slab と結果が変わる。γ を入力で上書きできる案は、導出できる値を保存することになるので退けた。

規準の版は Model に持たせず、式と表のドキュメントコメントとこの ADR に書く。版や慣例が変わったときに「古い Model を古い値で再現したいか」を決める。
