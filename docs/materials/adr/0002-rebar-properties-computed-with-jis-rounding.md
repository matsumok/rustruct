# 鉄筋の呼び名は公称直径だけを持ち、断面積と周長は JIS と同じ丸めで計算する

呼び名（D13 など）が持つ値は公称直径だけとする。公称断面積と公称周長は、公称直径から JIS G 3112 と同じ式と有効数字で求め、JIS Z 8401 の偶数丸め（銀行家丸め）で丸める。すべての呼び名について、計算した値が JIS の表と一致することをテストで確かめる。種類と呼び名は、現行の JIS G 3112 の全部を enum にする。種類には今は記号だけを持たせ、降伏点や許容応力度は、それを使う RC の Tool の一本で規準と一緒に決める。

表の値を定数で写す案も検討した。表との照合だけでレビューできるが、導出できる値を持つことになる。丸めまで JIS に揃えて計算すれば表と同じ数が出るので、持つ値を公称直径の1つに絞り、表との一致はテストで守ることにした。

種類と呼び名の一覧、公称直径、有効数字の桁は原典で確かめてから、実装と同じ変更でここに出典つきで書く。
